## 6. 상태 처리
| 상황 | 처리 · 문구(코드 원문) |
|---|---|
| 완결 연도 없음 | 공통 `period_control` 안내 + stop |
| 조건에 맞는 품목군 없음 | `st.info("조건에 맞는 품목군이 없습니다. 분류나 50% 필터를 바꿔 보세요.")` |
| 기간에 수입 실적 없는 품목군 | 각주 「{기간} 관세청 수입 실적(>0)이 없어 표에서 뺀 품목군: …」 |
| 분석 제외 | 각주 「수집 24개 중 규칙(R1 OR R2) 미해당 11개는 이 표에 없습니다(⑤ DATA INFO)」 |

| 과천 열 | 두지 않음 — 「과천시 소재 수입자 비중(추정)은 홈 KPI·⑤ DATA INFO에서 봅니다」(M7 채택은 홈 KPI 1장, 현황표 열 아님) |
| B1·B2 열(`v_review_list` 사용 시) | NULL = 「미확인」, 0 = 「확인된 없음」, B2 = 「대응표 없음」, B1 = 「대응 근거 없음」 — 「미적재」라 쓰지 않음 |
| 부분연도 | 기간 선택지에서 제외 |

## 7. 표현 경계
- 「추가 검토 목록」이지 「우선순위 확정」이 아니다. 「위험」「의존율」 금지 — 트리맵 색 범례는 「1위 점유율(%)」.
- 「여러 해를 고르면 기간 합계 점유율로 HHI 계산(연도별 HHI 평균 아님) · 수입국 수 = 수입 실적(>0) 있는 국가 수」.
- 수출/수입 비율 도움말: 「1보다 크면 수출이 수입보다 많음. HS6 합계라 민수 반도체가 대부분」 — 국가 전체(민수 포함).
- 「관련 군급(후보)」 열은 두지 않는다 — 카테고리 맵(HS6↔FSC 대응) 2026-09-21 폐기. B2·조달 건수를 HS6에 붙이지 않는다.
- R1·R2 = 「관세청 HS10 세분류(군용전용 · 항공/항행)로 진입」, R3 = 「전략물자 이중용도 통제품목(참고, 단독 진입 아님)」. R4(B2 국산화개발품목 대응)는 09-21 제외 — 표·캡션에 쓰지 않는다.
- 트리맵·산점도 캡션에 「국가 전체 수입(민수 포함) 기준이며 군수 수요 비중이 아닙니다」.
- 검토표 6항목(후보)은 「확인된 사실」과 「추가 확인사항」을 분리하고, 「국방 관련 근거」에 FSC 후보·B2 건수를 HS6 근거로 쓰지 않는다.

## 8. 자연어 구상 (Claude 초안 → 사용자 수정)
30초 읽기: 트리맵에서 면적 큰 칸(수입액)과 진한 칸(1위국 쏠림)이 겹치는 품목군을 찾는다 → 산점도 오른쪽 위(수입 크고 HHI 높음)를 확인한다 → 표 상단(HHI 내림차순)의 품목군 이름과 선정 근거 R1·R2를 읽는다 → CSV로 내려받는다.

강조점: 표가 주인공. 트리맵·산점도는 같은 조건의 다른 시선일 뿐이므로 크기를 표보다 작게. 50%·2,500 기준선은 ①·🔎와 같은 스타일. 벤치마킹 반영(09-20): SIPRI식 트리맵 채택, 칸 라벨 「품목군 · 1위국 %」, 분류 칸 클릭으로 확대. 후보: 행을 고르면 아래에 「선택 품목군 검토표」 6항목이 펼쳐지는 구조(idea-review §4 ③) — 근거 열은 ①(집중도)·②(FSC 후보, 참고)·⑤(출처)를 링크로만 잇는다.
