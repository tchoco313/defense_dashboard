# 01_figma_setup — Figma 착수 규격 (전원 공용)

작성: Claude 2026-09-21. 근거: 6차 회의(09-21) 액션 「내일까지 가입 및 agent 연결」·「각자 피그마로 .md파일/이미지 구현 후 공유」.
이 문서는 **Figma에서 무엇을 어떤 값으로 그리는지**만 정한다. 화면이 답하는 질문·데이터·집계 정의는 `00_common.md`와 페이지별 `dashboard/specs/<번호>_<키>.md`에 있고, **값이 어긋나면 md가 우선**이다(`00_common.md` §7).

> **먼저 읽을 것**: 본인이 맡은 페이지의 md §1(질문) · §3(레이아웃) · §4(차트 명세) · §7(표현 경계). Figma는 그 §3을 그림으로 옮기는 자리다.

## 1. agent(MCP) 연결

Figma MCP는 **Figma → 읽기** 방향이다(노드를 읽어 md §3·§4를 맞추는 용도). 그리는 것은 사람이 한다.

| 방식 | 조건 | 비고 |
|---|---|---|
| **Framelink `figma-developer-mcp`** | 개인 액세스 토큰(무료 요금제 가능) | 권장 — 아래 설정이 이것 |
| Figma 공식 Dev Mode MCP | Figma 데스크톱 앱 + Dev Mode(유료 좌석) | 무료 요금제에서는 안 됨 |

`.mcp.json`에 `figma` 항목이 들어 있다. 토큰은 저장소에 넣지 않고 **각자 환경변수**로 준다.

1. Figma → 우상단 계정 → Settings → Security → **Personal access tokens** → 새 토큰 발급(스코프: File content 읽기)
2. `~/.zshrc`(맥) 또는 사용자 환경변수(윈도우)에 `export FIGMA_API_KEY="figd_…"` 추가 후 터미널 새로 열기
3. Claude Code 재시작 → `/mcp`로 `figma` 연결 확인

토큰은 **비밀번호와 같다.** 저장소·회의록·드라이브·채팅에 붙여넣지 않는다.

## 2. 파일·페이지 구조

무료 요금제는 파일·페이지 수 제한이 있으므로 **파일 하나**에 Figma 페이지를 나눈다.

| Figma 페이지 | 내용 | 담당 |
|---|---|---|
| `00 Foundations` | 색 스타일 · 텍스트 스타일 · 컴포넌트(§3~§6) | 조장(먼저 만든다) |
| `10 홈` | `10_home.md` §3 | 동현 |
| `20 ① 수출입` | `20_trade.md` §3 | 동현 |
| `2x 핵심` | 21 · 22 · 24 | 조장 |
| `3x 배경` | 30 · 31 · 32 · 33 · 34 | 조장 |
| `9x 정보·조회` | 90 · 91 | 지수 |

`00 Foundations`가 먼저 올라가야 나머지가 같은 스타일을 쓴다. 다른 사람이 만들기 전에 이것부터 공유한다.

2026-09-21 조장 결정으로 **23 제한률 시나리오 · 35 국내 지도는 폐기** — 그리지 않는다. **24 과천 비중은 채택**(표현 히트맵), **34 국내 조달은 배경으로 유지**. 조장 몫은 Foundations + 8개(21 · 22 · 24 · 30 · 31 · 32 · 33 · 34).

## 5. 프레임 규격 · 그리드

| 항목 | 값 | 근거 |
|---|---|---|
| 프레임 | **1440 × 1024** (Desktop) | `.block-container{max-width:1440px}` |
| 좌우 여백 | **32** | `.block-container{padding:0 32px 24px}` |
| 콘텐츠 폭 | **1376** | 1440 − 32×2 |
| 레이아웃 그리드 | Columns **12** · Gutter **12** · Margin **32** · Stretch | `st.columns` 대응 |
| 모바일 | **만들지 않는다** | Streamlit이 자동 축소. `00_common` §9 「모바일/좁은 폭 = 없음」 |

상단바: 폭 1440(좌우 여백 밖까지 꽉 참), 높이 ≈ 62, 배경 `topbar-bg`, 아래 1px `line`, 안쪽 여백 14 / 32. 내부는 브랜드 3.2 : 메뉴 7 : 기준일 1.6 비율.

## 6. 컴포넌트 — **Streamlit 어휘로만** 만든다

아래 6개 밖의 요소는 그리지 않는다. 그리면 Streamlit에서 구현할 수 없다.

| 컴포넌트 | 규격 | 대응 코드 |
|---|---|---|
| **상단바** | §5 참조. 선택된 메뉴 = 배경 `panel2` + 아래 2px `accent` 밑줄, 라운드 8, 안쪽 5/10 | `ui.top_bar()` |
| **구역 틀** | 1px **점선** `zone-line`, 라운드 14, 안쪽 여백 30/16/16, 바깥 여백 12/0/16. 왼쪽 위 −11 · 좌 16에 태그(배경 `accent`, 글자 `#08101f`, 라운드 20, 안쪽 3/10) | `ui.zone(key, tag)` |
| **카드** | 배경 `panel`, 1px `line`, 라운드 12, 안쪽 14/16 | `.card` |
| **KPI 카드** | 카드 + 라벨(`kpi-label`) / 값(`kpi-value`) + 단위(`kpi-unit`) / 설명(`kpi-sub`). 배지는 라벨 오른쪽 | `ui.kpi()` |
| **KPI 줄** | 가로 **5등분**(또는 4등분), 간격 **12**, 높이 동일 | `.kpis` / `.kpis.k4` |
| **필터 줄** | 드롭다운 · 슬라이더 · pills · 세그먼트 버튼. **사이드바 없음** | `st.selectbox` 등 |

차트는 **자리표시자 사각형 + 제목 + 범례**로만 둔다. 차트 내부 디자인은 Plotly가 그리므로 Figma에서 정해도 옮겨지지 않는다. 정할 것은 **크기 · 위치 · 제목 문구 · 범례 색**뿐이고, 이는 각 md §4에 적는다.

### 그리지 않는 것 (Streamlit에서 구현 불가·금지)

- 자유 배치(절대 좌표) 레이아웃 — 위→아래 블록과 `st.columns` 격자만 가능
- 커스텀 그림자 · 그라데이션 · 유리 효과
- 마우스 올림(hover) 상태, 애니메이션, 전환 효과
- 3D 차트 · 게이지 · 왜곡 인포그래픽 (`PROJECT.md` UI/UX 원칙 3)
- 무기체계 사진 등 이미지 (저작권·출처 문제 — `benchmark-ui-changes-2026-09-20.md` §1 #4)

## 7. 그린 다음에 할 것

1. 프레임을 우클릭 → **Copy link to selection** → 해당 페이지 md **§0 표의 「프레임(노드) URL — 데스크톱」**에 붙인다.
2. Figma 파일 URL은 `00_common.md` §7 표에 한 번만 적는다.
3. 페이지 md 맨 위 **상태 줄을 「확정」**으로 바꾼다.
4. 조장에게 **"specs 처리해줘"** — Figma 노드를 읽어 §3·§4를 맞추고 Streamlit으로 이식한다(절차 `00_common.md` §11).

§8 「자연어 구상」 칸은 **그림 대신 말로 적는 자리**다. Figma를 안 그려도 여기에 적으면 목업이 만들어진다.

## 8. 회의 결정 반영 (09-21 6차)

Figma에 그릴 때 아래는 이미 정해진 것으로 본다.

| 항목 | 결정 |
|---|---|
| 제목 | **「수출입 및 국산화 현황」** — 「의존도」·「모니터링」은 제목에 쓰지 않는다(M1) |
| 부제 | **미정** — 「부제(M8 결정 대기)」 플레이스홀더를 둔다 |
| 「반도체」 | 주제·제목·설명 어휘에서 빼고 **분류 라벨로만**. 품목은 HS6 19개 그대로(M5) |
| 국내조달 계약 | **부록(정보전달)** 성격 — 핵심 근거 자리에 두지 않는다(M2) |
| 과천 비중 | **채택**, 표현은 **히트맵**. 라벨은 「과천시 소재 수입자 비중(방위사업청 소재지), 추정」 — **「하한」 금지**(M7) |
| 전자 판정 | FSG 58·59·60 **확정** → 「잠정」 배지 제거(M4) |
| 화면 순서 | **미정**(M3) — 프레임 순서는 잠정, 번호는 `00_common.md` §9 식별자를 쓴다 |

`dashboard/ui.py`의 브랜드 글자는 아직 옛 제목(「주요 방산 전자부품 수입 의존도 · 국산화 현황」)이다. M1 반영은 조장이 별도로 한다 — `ui.py` 수정 후 공개 앱은 **Reboot 필요**(`benchmark-ui-changes-2026-09-20.md` §4).
