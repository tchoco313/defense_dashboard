# 01_design_system — 디자인 규칙 (전원 공용)

화면은 **틀 = 팀원 디자인 데모**, **겉모양 = UI/UX 참고 URL**로 만든다(2026-09-23 팀 결정). 데이터는 언제나 RDS 에서만 읽는다 — URL 은 디자인 참고용이다.

- 틀 원본: 팀 저장소 `K-Defense_대시보드_demo.py`(단독 실행 Streamlit, 숫자는 샘플) — https://github.com/tchoco313/defense_dashboard/blob/main/K-Defense_%EB%8C%80%EC%8B%9C%EB%B3%B4%EB%93%9C_demo.py
- 코드 정본: `app/kdesign.py`(색 토큰 · CSS · 사이드바 · 머리띠 · 구역 · 카드 · KPI · 탭 · 지도 · 도넛 · PNG 단추). `app/ui.py`는 페이지가 쓰던 이름을 kdesign 으로 잇는 호환 층이다.
- `app/mockup/common.css`·`20_trade.html`은 데모 전환 전(09-23 2차) 목업 기록이며 기준이 아니다.
- 화면이 답하는 질문 · 데이터 · 집계 정의는 `00_common.md`와 페이지별 md 에 있다. **데이터 사실은 md 우선.**

## 0. 판단 기준 — 믿고 쓸 수 있는가

1. **숫자 옆에 단위 · 기간**, 출처는 차트 · 표 오른쪽 아래 「?」 원에, 산식은 펼침에.
2. **실제 0 / 미적재 / 조회 실패**를 구분하고, 부분연도(2026)는 「1~8월」을 밝힌다.
3. 표현 경계(`00_common.md` §6): 「의존도」 금지, 수입액은 국가 전체(민수 포함), 국가는 선적국, 관세청 ↔ 조달 예산 합산 · 비교 금지, 관세청 HS ↔ FSC · NSN 연결 금지.

## 2. 색 · 글씨

값은 `app/kdesign.py` 머리(토큰)에만 둔다.

- **화면 틀**(바탕 · 사이드바 · 카드 · 버튼 · 탭 · 결론 제목의 강조 구절): 파랑 · 하늘 · 흰색.
- **데이터 범주**(국가 · 수입/수출 · 근거 태그): 한 톤이면 읽기 어려워(2026-09-23 팀 결정) dataviz 검증 팔레트 8색을 고정 순서로 쓴다 — 파랑 · 주황 · 청록 · 노랑 · 분홍 · 초록 · 보라 · 빨강(흰 바탕 색맹 ΔE 9.1 · 일반 19.6 통과). 9번째부터는 기타(회색)로 묶고 색을 돌려 쓰지 않는다.
- **수입 = 파랑, 수출 = 주황**(모든 차트 · 지도 · 도넛 · 조회에서 같은 짝). 부분연도 = 같은 색의 옅은 톤 + 점선.
- **크기(연속값)**: HHI 등급 · 히트맵 · 지도 구간은 한 계열 진하기(수입 지도 파랑, 수출 지도 주황).
- 증감은 오르면 빨강 ▲ · 내리면 파랑 ▼(2026-09-24 팀 결정). 옅은 배지 바탕 위 글자 대비 4.5:1 이상(`kdesign.UP` · `DOWN`).
- **글씨**: KPI 숫자 31.5px · 카드 제목 16px · 본문 · 설명 13px 안팎 · 차트 기본 13.5px 이상(2026-09-23 사용자 — 작게 만들지 않는다).

## 3. 넣지 않는 것 — 흔한 AI 대시보드처럼 보이지 않게

데모에 있어도 쓰지 않는다.

- 이모지 아이콘(메뉴 · KPI · 탭 · 버튼 · 대화상자). 메뉴에는 단색 Material 아이콘만.
- 그라데이션 · 큰 그림자 · 유리 효과 · hover 들썩임 · 등장 애니메이션 · 인트로 화면. HOME 회전 지구본은 데모의 대표 시각화라 남긴다(2026-09-24 팀 결정).
- 장식 문구 · 슬로건 · 마케팅 어휘(「인사이트」「스마트」, 느낌표). 머리띠 오른쪽은 자료 기간 · 적재일.
- 차트 안 세로 격자 · 축선, 게이지 · 3D.
- 데모의 화면 확대(zoom 1.1) — 빈 띠와 차트 마우스 어긋남을 만든다.

## 5. 내려받기

- **CSV**: 모든 결과 표. 머리줄에 조건 · 출처(기관 · 데이터명) · 데이터별 자료 기간 · 내려받은 날(`ui.csv_header`). 조회 화면은 고른 차트 모양대로 표를 다시 짠다.
- **PNG**: plotly 차트 아래 `ui.png_button(fig, 파일명, title=, source=)` — 누를 때 브라우저에서 지금 그린 그림을 결론형 제목 · 출처 줄과 함께 PNG 로 만든다(plotly.js 는 누를 때만 받는다 — 페이지를 열 때 받으면 화면이 멈춘다). HTML 도넛은 같은 값의 plotly 그림을 따로 싣는다.
- **출처(화면)**: 차트 오른쪽 아래 「?」 원(`ui.chart_source`) — 누르면 「기관 · 데이터명 · 자료 기간」이 펼쳐진다(2026-09-23 팀 결정). 해석 경계 문구(민수 포함 · 선적국 등)는 숨기지 않고 보이게 둔다.
- **자료 기준(머리띠)**: 머리띠 오른쪽 위 「자료 기준」 버튼(`ui.hero(..., stamps=[(이름, data_stamp)])`) — 누르면 「데이터 이름 · 기간」 줄이 흰 카드로 펼쳐진다(2026-09-24 팀 결정). DB 반영일은 넣지 않는다 — 출처 「?」와 CSV 머리줄에 있다.

- **DB 내부 정보는 보이는 곳에 쓰지 않는다**(보안, 2026-09-24 팀 결정): 화면 · 출처 「?」 · PNG · CSV 에 DB 표 · 뷰 · 열 이름, 「팀 DB」, DB 적재 · 반영일을 넣지 않는다. 공통 필터 `kdesign.public_source()`가 출처 · CSV 를 거르고, 산식 설명도 쉬운 말로 쓴다. 표 이름은 코드 · 주석 · `docs/`·`db/`에만.

## 6. 작업 · 검증 방법

1. 데모를 로컬에서 띄운다(`--theme.base light --server.port 8601`), 운영 앱은 8501.
2. Claude in Chrome 으로 데모(틀)와 참고 URL(겉모양)을 보고 옮긴다. 참고 URL 은 실제 화면을 캡처해 확인한다.
3. 화면 숫자를 DBHub 로 RDS 와 대조하고, 탭 · 버튼 · 필터 클릭과 CSV · PNG 내려받기를 확인한다.

Figma 는 나중에 만든다(2026-09-23 팀 결정). 연결은 `.mcp.json`의 `figma`(읽기 전용), 토큰(`FIGMA_API_KEY`)은 각자 환경변수로만 둔다.
