# 01_design_system — 디자인 규칙 (전원 공용)

이 문서는 **디자인의 규칙·이름·근거·참고 URL**만 둔다. 색·글꼴·크기·간격 같은 **실제 값은 적지 않는다.**

- 값의 정본: **`app/mockup/common.css`**(대표 화면 ①에서 생성·확정 — `app/roadmap.md` §2 2~3단계). 생기기 전까지는 실행 중인 앱의 토큰 `app/ui.py`(색 상수·`inject_css`)와 `.streamlit/config.toml`이 현행 값이다.
- 화면이 답하는 질문·데이터·집계 정의는 `00_common.md`와 페이지별 `<번호>_<키>.md`에 있다. **데이터 사실은 md 우선, 디자인 값은 `common.css` 우선**(`00_common.md` §7·§11).
- 회의 결정(제목·부제·「반도체」 어휘·과천 라벨 등)은 `00_common.md` §8 한 곳에만 있다.

## 2. 색 — 역할과 고정 규칙

토큰 이름은 `common.css`의 CSS 변수·Figma 색 스타일 이름과 같게 쓴다(값은 `common.css`).

| 토큰 | 역할 |
|---|---|
| `bg` · `topbar-bg` | 페이지 배경 · 상단바 배경 |
| `panel` · `panel2` | 카드 배경 · 카드2/선택된 메뉴 배경 |
| `line` · `zone-line` | 카드 테두리·차트 격자 · 구역 점선 테두리 |
| `text` · `muted` · `caption` | 본문 · 보조 글자(라벨·축) · 출처 캡션 |
| `accent` | 강조 · 구역 태그 · **수입 시리즈** |
| `exp` | **수출 시리즈** |
| `imp-dim` · `exp-dim` | 수입 · 수출 부분연도(점선) |
| `up` · `dn` | KPI 전년비 증가 · 감소 |
| `badge-text` · `badge-line` | 「잠정」·「인용」·「정부안」 배지 |
| 국가 색 | 국가별 고정색(US·TW·CN·SG·VN·JP) + 추가 국가 5색 + 기타 1색. 지도·막대 범례에서 같은 국가는 같은 색 |
| 지도 색 | 육지 · 바다 · 국경/해안선 |

**고정 규칙** — 팔레트를 바꿔도 유지한다.

- **수입 = 파랑 계열 · 수출 = 주황 계열 · 부분연도 = 같은 색의 저채도 + 점선.**
- 빨강은 경고·감소에만 쓴다.
- 다크 테마만 만든다(현행 다크 유지, 09-22 결정). 라이트 테마는 없다.

## 3. 글꼴 · 텍스트 역할

글꼴 계열(한글 우선 순서)과 크기·굵기는 `common.css`에 둔다. 여기서는 역할 이름만 고정한다.

| 역할 | 쓰는 곳 |
|---|---|
| `brand` · `brand-sub` | 상단바 브랜드 · 그 아래 한 줄 |
| `page-h` | 페이지 제목 |
| `zone-tag` | 구역 태그 |
| `card-h` · `card-h-sub` | 카드 제목 · 제목 옆 보조 |
| `kpi-label` · `kpi-value` · `kpi-unit` · `kpi-sub` | KPI 라벨 · 큰 숫자 · 단위 · 아래 설명 |
| `nav` | 상단 메뉴(선택 시 `text` 색) |
| `note` · `caption` · `badge` | 설명문 · 출처 캡션 · 배지 |

## 4. 프레임 · 그리드 원칙

- **데스크톱 한 장**만 설계한다. 모바일은 만들지 않는다(Streamlit이 자동 축소, `00_common.md` §9).
- 폭·여백은 `.block-container` 값 하나를 따른다(`common.css`). 격자는 `st.columns`에 대응하는 12열.
- 배치는 **위→아래 블록 + `st.columns` 격자**뿐이다. **사이드바 없음** — 필터는 본문 필터 줄에 둔다.

## 5. 컴포넌트 — Streamlit 어휘 6개

아래 6개 밖의 요소는 목업·Figma에 넣지 않는다(Streamlit에서 구현할 수 없다).

| 컴포넌트 | 구성 | 대응 코드 |
|---|---|---|
| **상단바** | 브랜드 · 메뉴 · 기준일. 선택된 메뉴 = `panel2` 배경 + `accent` 밑줄 | `ui.top_bar()` |
| **구역 틀** | `zone-line` 점선 테두리 + 왼쪽 위 `accent` 태그 | `ui.zone(key, tag)` |
| **카드** | `panel` 배경 + `line` 테두리 | `.card` |
| **KPI 카드** | 카드 + 라벨 / 값 + 단위 / 설명. 배지는 라벨 오른쪽 | `ui.kpi()` |
| **KPI 줄** | 가로 5등분(또는 4등분), 높이 동일 | `.kpis` / `.kpis.k4` |
| **필터 줄** | 드롭다운 · 슬라이더 · pills · 세그먼트 버튼 | `st.selectbox` 등 |

**차트**는 자리표시자 + 제목 + 범례까지만 정한다. 내부 디자인은 Plotly가 그리므로(`ui.style_fig`) 목업에서 정해도 옮겨지지 않는다. 크기 · 위치 · 제목 문구 · 범례 색만 각 md §4에 적는다.

**상태 5종**(로딩 중 · 데이터 없음 · 조회 실패 · 미적재 · 부분연도)은 목업에 모두 넣는다. 문구는 각 md §6.

### 넣지 않는 것

- 자유 배치(절대 좌표) 레이아웃
- 커스텀 그림자 · 그라데이션 · 유리 효과
- 마우스 올림(hover) 상태, 애니메이션, 전환 효과
- 3D 차트 · 게이지 · 왜곡 인포그래픽 (`PROJECT.md` UI/UX 원칙 3)
- 무기체계 사진 등 이미지 (저작권·출처 — `benchmark-ui-changes-2026-09-20.md` §1 #4)

## 6. Figma (선택)

기준은 `common.css`이고 Figma는 표현일 뿐이다. 대표 화면 ①이 Streamlit까지 통과해 `common.css`가 확정되기 전에는 그리지 않는다. 안 그린 페이지는 md §8 「자연어 구상」으로 Claude가 `common.css` 기반 목업을 만든다.

**연결** — `.mcp.json`의 `figma`(Framelink `figma-developer-mcp`, 무료 요금제 가능, **Figma → 읽기**). 토큰은 각자 환경변수로만 둔다.

1. Figma → Settings → Security → **Personal access tokens** → 발급(스코프: File content 읽기)
2. `FIGMA_API_KEY` 환경변수 등록(맥 `~/.zshrc`, 윈도우 사용자 환경변수) → 터미널 새로 열기
3. Claude Code 재시작 → `/mcp`로 `figma` 연결 확인

토큰은 비밀번호와 같다. 저장소·회의록·드라이브·채팅에 붙여넣지 않는다.

**파일 구조** — 파일 하나에 Figma 페이지를 나눈다.

| Figma 페이지 | 내용 | 담당 |
|---|---|---|
| `00 Foundations` | §2·§3 이름 그대로 색·텍스트 스타일 등록(값은 `common.css`), §5 컴포넌트 | 조장(먼저) |
| `10 홈` · `20 ① 수출입` | 10 · 20 | 동현 |
| `2x 핵심` · `3x 배경` | 21 · 22 · 24 / 30 · 31 · 32 · 33 · 34 | 조장 |
| `9x 정보·조회` | 90 · 91 | 지수 |

23(제한률 시나리오)·35(국내 지도)는 폐기 — 그리지 않는다(`00_common.md` §9).
