# 01_design_system — 디자인 규칙 (전원 공용)

화면 디자인은 **동현님 새 디자인 `dashboard/demo/K-Defense_brandnew.py`를 그대로** 따른다(2026-09-28 팀 결정 — 「디자인도 동현님이 만드신 게 훨씬 낫다」). 화면 틀뿐 아니라 본문(색 · 카드 · KPI · 표 · 탭 · 차트 연출)까지 데모를 기준으로 삼는다. 데이터는 언제나 RDS 에서만 읽는다 — 데모의 숫자는 샘플이다.

- 디자인 원본: `dashboard/demo/K-Defense_brandnew.py`(단독 실행 Streamlit, 숫자는 샘플). 실행 `streamlit run dashboard/demo/K-Defense_brandnew.py --theme.base light --server.port 8601`.
- 코드 정본: `dashboard/frame.py`(머리글 · 상단 펼침 메뉴 · 서브 배너 · 왼쪽 블록 메뉴 · 빠른 메뉴 · 바닥글) · `dashboard/landing.py`(홈 첫 화면) · `dashboard/kdesign.py`(색 토큰 · 본문 CSS · 블록 · 경로 줄 · 카드 · KPI · 표 · 탭 · 차트 스타일 · 지구본 · 도넛 · 지도 · PNG 단추). `dashboard/ui.py`는 페이지가 쓰던 이름(수입 · 수출 · 국가 색 등)을 kdesign 으로 잇는 호환 층이다.
- `dashboard/mockup/common.css`·`20_trade.html`은 09-23 이전 목업 기록이며 기준이 아니다.
- 화면이 답하는 질문 · 데이터 · 집계 정의는 `00_common.md`와 페이지별 md 에 있다. **데이터 사실은 md 우선.**

## 0. 판단 기준 — 믿고 쓸 수 있는가

1. **숫자 옆에 단위 · 기간**, 출처는 차트 · 표 오른쪽 아래 「?」 원에, 산식은 펼침에.
2. **실제 0 / 미적재 / 조회 실패**를 구분하고, 부분연도(2026)는 「1~8월」을 밝힌다.
3. 표현 경계(`00_common.md` §6): 「의존도」 금지, 수입액은 국가 전체(민수 포함), 국가는 선적국, 관세청 ↔ 조달 예산 합산 · 비교 금지, 관세청 HS ↔ FSC · NSN 연결 금지.

## 2. 본문 부품 (데모 그대로)

- **카드**: 흰 바탕 · 테두리 `#dde5f2` · 둥근 14px · 옅은 그림자, 커서를 올리면 2px 떠오른다.
- **KPI**: 위 파란 선(4px) · 왼쪽 위 아이콘 배지(단색 Material, 카드 순서마다 파랑 · 청록 · 보라 · 주황 · 분홍 · 하늘 바탕) + 굵은 제목 · 가운데 큰 숫자 · 아래 설명. 한 줄에 5장 = 3 + 2, 6장 = 3 × 2, 4장 = 2 × 2. 아이콘은 제목 낱말로 고른다(`kdesign.KPI_ICON`). 차례로 떠오르며 나타난다.
- **카드 제목**: 왼쪽 파란 막대 + 굵은 결론 문장, 핵심 구절만 파랑.
- **표**: 머리줄 옅은 파랑, 줄에 커서를 올리면 옅게 칠함, 추이선(스파크라인)은 왼쪽부터 그려진다.
- **핵심 지표 카드**: 둥근 색 아이콘 + 라벨 · 큰 숫자.
- **탭**: 폴더형 — 고른 탭이 아래 패널과 한 장으로 이어진다.
- **차트**: 옅은 가로 · 세로 격자, 막대는 차례로 자라고 선은 왼쪽부터 그려진다(`kdesign.CHART_ANIM`). 도넛은 두꺼운 링 · 커서를 올린 조각이 커진다. 세계지도는 옅은 파랑 바탕 · 라벨이 튀어나오며 나타난다.
- **순위 · 점유율 막대 · 절차 원 · 깔때기**: 데모 색 · 둥근 모서리 · 뻗어 나오는 연출.

## 3. 색 · 글씨

값은 `dashboard/kdesign.py` 머리(토큰)에만 둔다.

- **틀 색**: 강조 파랑 `#2b6ef6` · 짙은 파랑 `#003899`(머리글 · 펼침 메뉴 · 제목 칸) · 글자 `#16233f` · 보조 글자 `#6b7a99` · 선 `#dde5f2`. 페이지 바탕은 흰색.
- **데이터 범주 8색**(데모 팔레트): 파랑 `#2b6ef6` · 청록 `#17c8b5` · 주황 `#ff9f43` · 보라 `#7c6cf0` · 분홍 `#ff6b9a` · 하늘 `#38bdf8` · 연두 `#84cc16` · 남색 `#1e3a8a`. 9번째부터는 기타(회색)로 묶는다. 청록 · 연두 · 하늘은 흰 바탕 대비가 낮아 범례 · 값 라벨 · 표와 함께 쓴다.
- **국가 색**(모든 차트 같은 색): 미국 파랑 · 대만 청록 · 중국 주황 · 일본 보라 · 베트남 분홍 · 홍콩 하늘 · 싱가포르 연두 · 그 밖 1개국 남색(`ui.COUNTRY_COLOR`).
- **수입 = 파랑 `#2b6ef6`, 수출 = 청록 `#0fa595`**(모든 차트 · 지도 · 조회에서 같은 짝). 부분연도 = 같은 색의 옅은 톤 + 점선.
- **크기(연속값)**: 지도 구간은 수입 파랑 · 수출 청록 한 계열 진하기, HHI · 히트맵은 파랑 한 계열.
- **증감**: 오르면 빨강 ▲ · 내리면 파랑 ▼(2026-09-24 사용자), 흰 바탕 글자 대비 4.5:1 이상(`kdesign.UP` · `DOWN`).
- **글씨**: 글꼴 Pretendard. KPI 숫자 36px · KPI 제목 17px · 카드 제목 16px · 본문 · 설명 13px 안팎 · 차트 13px 이상. 데모는 화면을 1.1배 확대해 크게 보였고, 운영 앱은 확대를 끄는 대신 작은 글씨를 13px 안팎으로 키웠다(2026-09-23 사용자 — 작게 만들지 않는다).

## 5. 내려받기 · 출처

- **CSV**: 모든 결과 표. 머리줄에 조건 · 출처(기관 · 데이터명) · 데이터별 자료 기간 · 내려받은 날(`ui.csv_header`). 조회 화면은 고른 차트 모양대로 표를 다시 짠다.
- **PNG**: plotly 차트 아래 `ui.png_button(fig, 파일명, title=, source=)` — 누를 때 브라우저에서 지금 그린 그림을 결론형 제목 · 출처 줄과 함께 PNG 로 만든다(plotly.js 는 누를 때만 받는다). HTML 도넛은 같은 값의 plotly 그림을 따로 싣는다.
- **출처(화면)**: 차트 오른쪽 아래 「?」 원(`ui.chart_source`) — 누르면 「기관 · 데이터명 · 자료 기간」이 펼쳐진다.
- **자료 기준(경로 줄)**: 서브 배너 아래 경로 줄 왼쪽 「자료 기준」 버튼(`ui.hero(stamps=[(이름, data_stamp)])`) — 누르면 「데이터 이름 · 기간」 줄이 흰 카드로 펼쳐진다.
- **DB 내부 정보는 보이는 곳에 쓰지 않는다**(보안, 2026-09-24 사용자): 화면 · 출처 「?」 · PNG · CSV 에 DB 표 · 뷰 · 열 이름, 「팀 DB」, DB 적재 · 반영일을 넣지 않는다. 공통 필터 `kdesign.public_source()`가 출처 · CSV 를 거르고, 산식 설명도 쉬운 말로 쓴다. 표 이름은 코드 · 주석 · `docs/`·`db/`에만.

## 6. 작업 · 검증 방법

1. 데모를 로컬에서 띄운다(`--theme.base light --server.port 8601`), 운영 앱은 8501.
2. 데모와 운영 앱을 같은 폭(1600 · 1280 · 1024 · 390px)으로 캡처해 나란히 비교한다.
3. 화면 숫자를 DBHub 로 RDS 와 대조하고, 탭 · 버튼 · 필터 클릭과 CSV · PNG 내려받기를 확인한다.
