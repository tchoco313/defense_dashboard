## 1. 이 화면이 답하는 질문
- 이 대시보드의 숫자는 **어디서 왔나** — 출처·포털 ID·대상 기간·확보일·원본 건수·수집 방식.
- **어떻게 골랐고 어떻게 계산했나** — 품목 선정 규칙 R1·R2(R3 참고, R4 제외), 지표 정의(수입액·1위 공급국 점유율·HHI·수입국 수).
- 화면에서 만나는 **말이 무슨 뜻인가** — 용어 15행.
- **무엇을 뜻하지 않나** — 쓰지 않은 데이터와 이유, 과장 금지 목록.

페이지 머리 문구(코드 원문): 「이 대시보드의 숫자가 어디서 왔고, 어떻게 계산했고, 무엇을 뜻하지 않는지 적어 둔 곳입니다.」

| 지표 | 1위 공급국 점유율 | 1위 국가 수입액 ÷ 품목군 수입액 |
| 지표 | 집중도(HHI) | Σ(국가별 점유율 %)², 0~10,000. 2,500 이상 = 높은 집중. 수입 집중도이며 위험도가 아닙니다 |
| 지표 | 선적국 | 관세청 통계의 국가 기준. 원산지와 다를 수 있습니다(홍콩 · 싱가포르 경유 등) |
| 지표 | 민수 포함 | 수입액 · 수출액은 국가 전체 교역액입니다. 군수 몫만 따로 떼어 낸 통계는 없습니다 |
| 자료 | 국외 조달계획 | 방위사업청이 공개하는 품목 단위 국외 조달 계획. 계획이지 계약 · 실적이 아닙니다 |
| 자료 | 국산화개발품목 | 방위사업청 국산화개발 완료 부품 목록(지상 {n}개 사업). 부품 수이지 국산화율이 아닙니다 |
| 표시 | 부분연도 | 1년이 다 차지 않은 해(2026년은 8월까지). 연간 비교 · KPI · 전년비에서 뺍니다 |

## 7. 표현 경계
- **「군 직접 수입 하한」·「하한선」을 쓰지 않는다.** 과천 비중은 2026-09-28 화면에서 뺐다(M7) — 「쓰지 않은 데이터」 표에 이유만 둔다.
- 「국산화율 N%」를 쓰지 않는다. 「완료 부품 목록(지상 {n}개 사업)」이며 빈칸은 「국산화 안 됨」이 아니라 「이 자료에 없음」.
- 「해외 의존율」·정의 없는 「의존도」를 쓰지 않는다. HHI·점유율은 **수입 집중도**이지 군수 의존도나 위험도가 아니다.
- **예측·조기경보·실시간 감시를 하지 않는다**고 명시한다.
- **HS 품목군(관세청)과 군급(방사청)을 연결하지 않는다.** 두 축을 나란히 놓을 뿐, 「부품의 수입국 → 무기체계 → 국산화 상태」를 잇는 설명은 이 자료로 하지 않는다.
- 국외 조달계획(원화 계획)과 관세청 수입액(달러 실적)을 합산·비율·직접 비교하지 않는다.
- 「전자부품 데이터 1만 건」이라고 쓰지 않는다. 1만 건 요건은 **원본 건수**로만 말하고, 관측 대상이 서로 다른 자료로 센다.
- 원본 건수는 **내려받아 파서로 센 수**다. 포털 표시 건수·API 총건수·반복 수집분을 넣지 않는다.
- 근거 문서 캡션(코드 원문): 「근거 문서: docs/data-sources.md · docs/reference/hs-whitelist-definition.md · docs/reference/data-cleaning-rules.md §2-6 · docs/report/data/data-usage-decision-2026-09-18.md · docs/idea-review.md §3 · 지표 검토 docs/report/app/app-metrics-review-2026-09-20.md」

## 8. 자연어 구상
30초 읽기 순서: ① 출처 표에서 「무슨 기관의 무슨 자료를, 언제, 몇 건 받았나」를 한눈에 본다 → ② 규칙 카드에서 「13개는 어떻게 골랐나(R1·R2)」를 읽는다 → ③ 지표 카드에서 HHI·점유율 계산식을 확인한다 → ④ 모르는 말이 나오면 용어 표에서 찾는다 → ⑤ 마지막 두 구역에서 「이 화면이 하지 않는 말」을 확인한다.

강조점: 이 화면은 **방어 문서**다. 발표 질의응답에서 「그 숫자 어디서 났습니까」·「국산화율입니까」·「예측입니까」에 바로 손가락으로 가리킬 수 있어야 한다. 그래서 차트를 넣지 않고 표와 카드만 둔다. 카드 제목은 질문형 평서문(「…이렇게 골랐습니다」·「…이렇게 계산합니다」·「왜 …라고 쓰지 않나」)으로 고정해, 읽는 사람이 제목만 훑어도 논점을 알게 한다. 숫자는 문장 안에 박아 넣지 않고 DB에서 읽어 넣는다 — 문서와 화면이 따로 놀지 않게.

인터랙션: 표 2개는 오른쪽 위 돋보기로 검색(용어·제외 데이터). 출처 표의 「링크」는 포털 원문으로 새 탭. 벤치마킹 반영(09-20): 조원 아이디어 「용어 사전」을 이 화면의 `p5_terms` 구역으로 받아들이되, DB 계층·테이블명 같은 내부 용어는 빼고 **사용자(정책·예산 / 연구·분석 / 방산 중소·벤처)가 화면에서 만나는 말만** 골랐다.
