## 4. "예산이 얼마나" — 조달계획과의 관계

품목군별 예산은 산출하지 않는다. 방사청 국외조달 조달계획(A7)에는 HS 코드가 없고 `대표품명`뿐이므로, 예산은 **집행유형(장비/부품/정비 등) × 연도** 단위로만 집계하고, 품목군과는 `system_family` 키워드(레이더·음탐·통신·항법 등)로 후보를 표시하는 수준에 그친다. 조달계획 예산(원, 집행 예정)과 관세청 수입액(CIF 달러, 실적)은 합산·직접 비교하지 않는다(`idea-review.md` §3-15).

## 5. 국산화 완료 확인

`related_fsc`가 있는 품목군만 B2 국산화개발품목으로 `개발 완료` 건수를 셀 수 있다(후보 합계 약 460행, 지상 기동·화력 28개 사업 한정·시점 미상). 항공·함정·유도 계열(841191·880730·901420)은 "B2 범위 밖". 국산화율은 산출하지 않는다(§3-14).

## 6. 외부 검증 축 — 전략물자 통제품목 (2026-09-15 조사, 대조 미수행)

무역안보관리원(구 전략물자관리원) **HSK 연계표**(data.go.kr `15034135`, 2,161행, `품목번호(HSK 10자리)`·`품명(국문·영문)`·`통제번호`, 2026-05-22 수정, 이용허락 제한 없음)는 "전략물자에 해당하거나 해당 가능성이 있는 품목"을 HSK와 연결한 목록이다. HSK 앞 6자리와 위 21개 HS6를 대조하면 근거 키 `전략물자`를 추가할 수 있다. "해당 가능성" 목록이므로 대응이 있어도 "통제품목임"이 아니라 "통제품목과 겹치는 HS6"로만 쓴다. 온라인 검색: yestrade.go.kr `hsk-control-search`.

(2026-09-16) 수용 준비 완료, **적재는 미수행**: 사용자가 CSV를 `data/raw/kosti/hsk_control_15034135.csv`에 두고 `db/meta_dataset.csv`에 `kosti_hsk_control` 행을 추가한 뒤 `python scripts/load_db.py --raw --tables raw_hsk_control`(`docs/runbook/commands.md`). 적재 후 §7의 `hsk_control_hs10_ratio`·`hsk_control_imp_share`를 계산해 `civil_mix_basis='hsk'` 경로가 열린다.

### 7-2. `civil_mix` 도출 규칙 (팀 규칙, 문턱값 조정 가능)

1. `mil_hs10_share`가 있으면 → `< 1%` **높음** / `1~20%` 중간 / `≥ 20%` 낮음
2. 없고 `aero_hs10_share`가 있으면 → `< 20%` 높음 / `20~80%` **중간** / `≥ 80%` **낮음**
3. 둘 다 없고 `hsk_control_hs10_ratio`가 있으면 → 문턱값 미정(적재 후 결정), 그때까지 NULL
4. 어느 것도 없으면 → NULL, `civil_mix_basis = '판단불가'`

문턱값 1 / 20 / 80%는 "군용 전용 신고가 1% 미만이면 수입 흐름은 사실상 민수", "항공기용이 80% 이상이면 범용 소비재 흐름이 아님"이라는 팀 규칙이며 통계적 근거가 있는 경계가 아니다. 규칙은 **"정량 근거로 도출"** 이지 "정량적으로 검증"이 아니다.

### 7-4. 검토 목록의 4축 (표시 원칙)

검토 목록 한 행은 ① 국방 관련성(`evidence` 키 + `b2_part_count` 등 §7-1 건수) ② 민수 혼합(`civil_mix` + `civil_mix_basis`) ③ 수입 집중도(`v_hhi_hs6_year`, 연도별 계산값, "국가 전체 수입(민수 포함)" 라벨 필수) ④ 국산화 상태(`v_review_list` `b1_status`·`b2_status`)로 읽는다. ①②는 품목군 고정 속성, ③④는 뷰 계산값이라 저장 위치가 다르다. 각 축은 값과 근거 등급을 함께 보여 준다. `priority`를 ①②의 근거 등급으로 자동 강등하는 규칙(예: `evidence='팀판단'`이고 `civil_mix_basis='판단불가'`면 priority 3)은 **제안**이며 미적용.
