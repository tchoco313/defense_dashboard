### 2-1. A1 관세청 품목별 국가별 수출입실적 — 핵심 ①

- **파일**: `customs_all_<HS6>.csv` ×**24**(2026-09-16 규칙 도출로 21→24; 추가 852910·901410·901490). 원본 **294,420**행(총계행 246 포함 — HS6당 11개, HS2022 신설 854142·854159·880730은 5개; 구 21개 268,909·총계 213). 2016.01~2026.08. 2026-09-18 팀 DB 실측 일치.
