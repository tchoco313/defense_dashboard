# 화면설계서 — 주요 방산 전자부품 수출입 및 국산화 현황 대시보드

훈수안이조 · 배포 주소 https://defense-trade.streamlit.app · 진입 파일 `dashboard/main.py`

## 1. 개요

### 1-1. 목적

무기체계의 탐지 · 통신 · 항법 · 제어를 맡는 전자부품에 대해, 공개 데이터만으로 다음 네 가지를 한 화면 흐름으로 보여 준다.

1. 분석 대상 13개 품목군(HS 6단위)을 **어느 나라에서 얼마나 들여오고 내보내는지**, 수입이 한 나라에 얼마나 쏠렸는지(공급국 집중도)
2. 군수품 분류(군 FSG · 군급 FSC)로 본 **전자 군급의 국외 조달계획**과 국내 계약 · 입찰 방식
3. 전자 군급 부품 중 **국산화개발을 마친 부품**
4. 이를 둘러싼 **정책 · 예산 · 국내 생산 기반**과 **데이터 출처 · 해석 경계**

화면은 「소개 → 전자부품 현황 → 군급 분류와 조달 → 국산화 현황 → 배경과 자료」 순서의 이야기로 이어지고, 각 대분류의 마지막 분석 화면 아래에 다음 대분류로 가는 링크가 있다. 숫자는 모두 운영 DB(AWS RDS MySQL)에서 읽는다.

### 1-2. 대상 사용자

| 사용자 | 주로 보는 화면 | 기대하는 것 |
|---|---|---|
| 정책 · 예산 담당 | 전자부품 현황 · 국산화 현황 · 배경과 자료 | 수입 쏠림이 큰 품목군, 국산화 진행, 정책 · 예산 흐름 |
| 연구 · 분석 | 전자부품 현황 · 상세 조회 · 데이터 출처와 검증 | 조건별 수출입 표 · 차트, CSV 내려받기, 산식과 출처 |
| 방산 중소 · 벤처 기업 | 군급 분류와 조달 · 국산화 현황 | 해외에서 조달하려는 전자 군급, 국산화가 이뤄진 군급 |

순위는 없다. 세 그룹 모두 같은 메뉴를 쓴다.

### 1-3. 화면 원칙

| 항목 | 원칙 |
|---|---|
| 화면 틀 | 흰 머리글 + 상단 메뉴(GNB) → 서브 배너 → 왼쪽 메뉴(LNB) + 본문 → 짙은 바닥글. 사이드바는 쓰지 않는다(`initial_sidebar_state="collapsed"`, `st.navigation(position="hidden")`) |
| 한 대분류 = 한 페이지 | 대분류의 소분류 화면을 위에서 아래로 이어 그린다. 왼쪽 메뉴의 소분류를 누르면 페이지를 다시 열지 않고 그 자리로 스크롤하고, 스크롤 위치에 따라 현재 소분류에 ✓ 표시가 붙는다 |
| 소분류 화면 순서 | 제목(아래 검은 줄) → 필터 → 「Q. 질문 + 답」 상자(질문 한 줄 + 결론 한 문장, 두괄식) → KPI 최대 4개 → 주 차트 + 보조 차트 → 읽는 법 → 「자세히 보기」(접힘) → 다음 대분류 링크. 제목 아래에 출처 줄은 두지 않는다 |
| 차트 제목 | 결론형 문장(강조 구절은 파랑) + 부제(단위 · 기간 · 기준 · 색의 뜻) |
| 색 | 바탕 `#eef3fb` · 글자 `#16233f` · 강조 파랑 `#1d4ed8` / `#2b6ef6` · 짙은 파랑(메뉴 · 제목 칸) `#003899`. 계열 8색 `#2b6ef6 #ff9f43 #17c8b5 #7c6cf0 #ff6b9a #38bdf8 #84cc16 #1e3a8a`, 기타 `#c3cede`. 수입 = 파랑 `#2b6ef6`, 수출 = 청록 `#0fa595`(모든 차트 · 지도에서 같은 짝). 공급 집중 「높음」 배지 `#1e3a8a` |
| 글꼴 · 배율 | Pretendard(웹 글꼴) → Apple SD Gothic Neo / 맑은 고딕. 화면 전체를 1.1배로 키워 보인다(차트 · 표 안쪽은 마우스 위치가 어긋나지 않게 배율을 되돌림) |
| 테마 | 라이트 테마 고정(`.streamlit/config.toml` + `static/light_theme.css`). OS 다크 모드에서도 같은 색 |
| 화면 표현 경계 | 화면 · PNG · CSV 에 DB 표 · 뷰 · 열 이름을 쓰지 않는다. 출처는 「기관 · 데이터명 · 자료 기간」만 적는다 |
| 정적 자원 | CSS · JS · 인트로 HTML 은 `dashboard/static/` 파일이며, CSS 의 `${이름}` 자리는 파이썬 값(색 · 폭)으로 채운다(`string.Template`) |

## 3. 화면별 명세

공통 표기 — **데이터** 칸의 이름은 RDS `defense_dashboard` 의 표 · 뷰이며, 모든 조회는 `dashboard/screens/rds.py`(소분류 화면) 또는 `dashboard/datacenter_viz.py`(상세 조회)를 거쳐 `dashboard/db.py` 의 `query()`(바인딩 파라미터 · 캐시 1시간)로 나간다. 관세청 금액 단위는 억 달러(상세 조회는 백만 USD), 예산은 억 원이다.

| 바닥글 | 로고(누르면 홈) · 「데이터 이용 안내 · 데이터 출처(→ P-06-3) · 용어 설명(대화상자) · 주의사항」 · 자료 목록(관세청 수출입무역통계 · 방위사업청 국내 · 국외 조달 · KOSIS 방산 가동률 · 열린재정 세부사업 예산) · 팀 이름 「훈수안이조」 · 「관련 사이트 바로가기」(관세청 · 방위사업청 · KOSIS · 열린재정 · 공공데이터포털) |
| 용어 설명 | 분야별 카드(수출입 · 공급 집중도 / 군수품 분류 / 조달 / 예산 · 산업 / 대시보드 규칙) — 바닥글의 단추로 열고, 본문은 다시 그리지 않는다 |
| 화면 출처 | 소분류 제목 아래에는 출처 줄을 두지 않는다. 데이터 출처 · 자료 기간 · 원본 건수는 P-06-3 「데이터 출처와 검증」 표에 모으고, 바닥글 「데이터 출처」 링크가 그 화면으로 간다. 상세 조회는 차트 · 표 아래 「?」 원을 누르면 출처가 펼쳐지고, 내려받은 CSV · PNG 에도 출처가 들어간다 |
| 출처 표기 규칙 | 기관 · 데이터명(공공데이터포털 데이터 ID) · 자료 기간만. DB 표 · 뷰 · 열 이름과 적재일은 화면 · PNG · CSV 에 쓰지 않는다 |

### 4-3. 오류 · 빈 데이터 처리

| 상황 | 처리 |
|---|---|
| DB 접속 실패(메뉴 페이지) | 본문 대신 「데이터를 불러오지 못했습니다({오류 종류}). 잠시 뒤 「다시 연결」을 눌러 주세요.」 + 「다시 연결」 단추. 접속 설정이 없으면 「데이터 연결 설정을 읽지 못했습니다(설정 오류)」. 호스트 · 계정 · 설정 키 이름은 화면에 쓰지 않고 서버 콘솔에만 남긴다 |
| 화면 예외 | 브라우저에는 예외 종류만 보인다(`client.showErrorDetails = "type"`), 전체 메시지는 서버 콘솔 |
| 홈 숫자 조회 실패 | 숫자 없는 문장으로 바꿔 쓴다(P-01) |
| 조건 결과 0건 | 차트 자리에 안내 상자 — 실제 0 과 조건 문제를 구분한다(예: 「{연도}년 수입 실적이 없습니다(실제 0)」, 「조건에 맞는 품목이 없습니다. 조건을 줄여 보세요」) |
| 선택 없음 | 「국가를 하나 이상 고르거나 「전체 국가 선택」을 켜 주세요」 등 무엇을 고르면 되는지 안내 |
| 부분연도 · 자료 공백 | 2026년(부분연도)은 연도 추세에서 빼고, 국외 조달계획 2018~2020 공백은 차트 아래 문구로 알린다 |
| 실패 결과 캐시 | 실패한 조회는 캐시하지 않아 다음 시도에서 바로 다시 읽는다 |

### 4-4. 내려받기 형식

| 형식 | 위치 | 내용 |
|---|---|---|
| CSV | 상세 조회 3곳(P-03-4 · P-04-5 · P-05-3) | UTF-8(BOM, 엑셀에서 한글이 깨지지 않음). 머리줄 `# 조건` · `# 출처` · `# 자료 기간(데이터별)` · `# 내려받은 날` 뒤에 표. 결과 카드 맨 아래 내려받기 줄에 지금 고른 표 탭의 단추 하나만 보인다. 수출입 HS 는 「결과 표」 탭에서 고른 차트 모양대로(예: 행 = 국가 · 열 = 연도 × 지표), 군수품 · 국산화개발은 표 탭마다 그 표 |
| PNG | 상세 조회 3곳의 차트 탭 · 수출입 HS 지도 탭 | 차트 = 화면 차트 + 결론형 제목 + 아래 출처 한 줄(넓힌 막대 차트는 넓힌 폭 그대로) · 지도 = 보이는 지도 그대로. 단추는 CSV 와 같은 자리(카드 맨 아래, 왼쪽에 출처 「?」) |
| 차트 도구 막대 | 모든 Plotly 차트 오른쪽 위 | 확대 · 축소 · 초기화 · 그림 저장(끌어서 확대 · 이동 · 선택 도구는 뺐다) |
