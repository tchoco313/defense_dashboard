# 작업 환경 · 글꼴 안내

이 프로젝트는 **macOS** 에서 만들었다. 다른 운영체제(특히 Windows)에서 파일을 열 때 달라 보일 수 있는 점을 모았다.

## 1. 발표 자료(포트폴리오 PPT)

- 글꼴은 **맑은 고딕(Malgun Gothic)** 으로 지정돼 있다(코드 부분만 Consolas). 글꼴 파일은 PPT 안에 넣지 않았다.
- 작업한 Mac 에는 맑은 고딕이 없어, 작업 중에는 macOS 가 비슷한 한글 글꼴(Apple SD Gothic Neo)로 바꿔 보여 줬다. 줄바꿈 · 글자 폭은 그 화면에 맞췄다.
- 그래서 **Windows PowerPoint 에서 열면 글자 폭이 조금 달라 몇몇 줄의 줄바꿈 위치가 바뀔 수 있다.** 내용은 같다.
- **작업자가 본 그대로의 화면은 함께 제출한 PDF**(`6_포트폴리오/01_훈수안이조_최종포트폴리오.pdf`)다. 배치를 확인할 때는 PDF 를 기준으로 본다.

## 2. 대시보드

- 본문 글꼴은 웹 글꼴 **Pretendard** 를 인터넷(jsDelivr CDN)에서 받아 쓴다. 운영체제와 상관없이 같은 글꼴로 보인다.
- 인터넷이 막혀 있으면 Windows 는 맑은 고딕, macOS 는 Apple SD Gothic Neo 로 대신 보인다. 지구본 · 지도 데이터와 국기 이미지도 인터넷에서 받으므로, 이 경우 그 부분만 빠진다(데이터 · 차트는 DB 에서 읽으므로 그대로 나온다).
- Chrome 에서 만들고 확인했다.

## 3. 노트북(EDA 그림)

- 한글 글꼴을 운영체제에 따라 고른다: macOS `AppleGothic` · Windows `Malgun Gothic` · 그 밖(Linux 등) `NanumGothic`.
- 저장된 실행 결과(그림)는 macOS 에서 그린 것이라 AppleGothic 으로 보인다. Windows 에서 다시 실행하면 맑은 고딕으로 그려진다(숫자 · 결과는 같다).

## 4. 설계서 PDF · 문서 생성 스크립트

- 설계서 PDF(`docs/제출/01~04`)는 `scripts/build_docs_pdf.py` 가 Pretendard 웹 글꼴로 만들었고, 글꼴이 PDF 에 들어 있어 어디서나 같게 보인다.
- 이 스크립트는 macOS 의 Chrome 경로(`/Applications/Google Chrome.app/...`)를 쓴다. Windows 에서 다시 만들려면 파일 맨 위 `CHROME` 값을 Chrome 실행 파일 경로로 바꾼다.
- `scripts/md_to_pdf.py`(간이 변환기)는 반대로 Windows 글꼴 경로(`C:/Windows/Fonts/NanumGothic*.ttf`)를 쓴다.

## 5. 실행 환경

| 항목 | 내용 |
|---|---|
| Python | **3.12 이상**(numpy · scipy 고정 버전이 요구). 작업 환경은 Python 3.14 |
| 패키지 | `requirements.txt` 에 버전을 고정했다 — `pip install -r requirements.txt` |
| DB | 로컬 실행은 **MySQL 8.0 이상**(덤프 복원 — `db/README.md`) |
| 명령 | 문서의 명령은 macOS/Linux 기준이다. Windows 는 `cp` → `copy`, `source .venv/bin/activate` → `.venv\Scripts\activate`, 경로의 `/` → `\` |

## 6. 파일 · 압축

- 문서 · 코드 · CSV 는 **UTF-8** 이다. Excel 에서 CSV 가 깨지면 `데이터 → 텍스트/CSV 가져오기` 에서 인코딩을 UTF-8(65001)로 고른다. (`data/reference/contract_class5_rules.csv` 만 BOM 이 붙어 있어 바로 열린다.)
- 로컬 실행 패키지 zip 은 파일 이름을 UTF-8 로 표시해 만들었다. Windows 기본 압축 풀기 · 반디집 · 7-Zip 에서 한글 파일 이름이 그대로 보인다. 아주 오래된 압축 프로그램에서 이름이 깨지면 위 프로그램으로 푼다.
- 시연 영상은 MP4(H.264, 1920×1080)라 Windows · macOS 기본 플레이어에서 재생된다.
