## 4. 팀 확인이 필요한 잠정 결정 (문서에 "잠정"으로 표기됨)

1. **뷰 전환 의미 변경 4건**(§2)을 그대로 둘지 — 특히 국외 API 전자 판정을 58·59·60 + NSN 전체로 넓힌 것.
2. `v_civil_mix_rule` 근거가 hsk 15로 바뀌었는데 저장 열은 판단불가 15 그대로. 어느 쪽을 화면에 쓸지.
3. KRIT 공고 순서(예비 < 본공고 < 수정 < 재공고) — 25-1차 수정↔재공고 순서.
4. 열린재정 세부사업 개편 연결표 22행(국방기술개발 단위사업만). 공식 개편 고시 미확인.
5. 장비명 표준명 803종 미확인 — 표준화 범위를 넓힐지, 후보 40종으로 갈지.
6. `class5` 5분류 키워드 사전 — 아직 없음. 사전 없이는 화면 ② 5분류 막대와 후보 테이블이 빈다.
7. 국외 입찰결과 문서 수치 정정(유찰 2,146·낙찰 348, 개찰 2025-03-27 시작) — 기획서 v3 수치와 다르면 기획서 갱신.
8. (09-19 저녁 추가) **테스트 업체 계약 6행 제외** — P2 검수 문서 #7 원안대로 `clean_excluded_row` PLACEHOLDER(업체명 `조달테스트업체Ⅰ`·`테스트업체1` 정확 일치, 주소·사업자번호도 가짜). 계약명·금액이 실제 같아 "업체명만 가명 처리된 실제 계약"일 가능성은 남음 — raw는 그대로라 되돌릴 수 있음. 집계 영향은 계약 단위 37,608→37,602(소액·소기업 −4, 경쟁실패 후 수의 −2), 금액 15.834조 불변.
