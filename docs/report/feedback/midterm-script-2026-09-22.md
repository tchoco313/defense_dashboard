## 2. 발표 요령

- **장마다 한 문장은 꼭 말한다.** 2장 "공개 도구가 없다" / 3장 "팀이 고르지 않고 규칙으로 걸렀다" / 5장 "차이 0" / 6장 "7개가 2,500 초과, 단 민수 포함" / 7장 "건수는 포털 숫자가 아니라 실측이고, 안 옮긴 열도 원본에 남아 있다" / 8장 "수치는 가상, 범위 기준으로 거른다". 시간이 밀리면 이 문장만 말하고 다음 장으로 넘어간다.
- **3장에서 24 → 13을 먼저 밝힌다.** 6장 집계가 왜 13개인지가 여기서 설명된다. 빠뜨리면 6장에서 질문이 나온다.
- **표는 읽지 않는다.** 4 · 5장의 표는 "핵심은 두 줄입니다"라고 짚기만 하고, 나머지는 눈으로 보게 둔다.
- **한계를 먼저 말한다.** "민수 포함", "팀의 분석 규칙", "검정은 표본이 작다", "시안 수치는 가상", "9장 그림은 옛 기준"을 질문받기 전에 말하면 같은 내용이 지적이 아니라 발표 내용이 된다.
- **8장은 시안을 하나하나 설명하지 않는다.** "참고할 것 셋, 넣지 않을 것 셋"만 말한다.
- **숫자 읽는 법을 정해 둔다.** HHI "에이치에이치아이", 98.9 "구십팔 점 구", 2,500 "이천오백". 294,420 같은 큰 수는 "약 29만 4천"으로 줄여 읽는다.
- **7장은 표를 읽지 않는다.** 왼쪽 표는 "시트 네 종류입니다"로 짚고, 오른쪽 세 카드(실측 · 보존 · 재생성)만 말한다. 검정 · 상관 질문이 오면 6장으로 돌아가 §3 표로 답한다.
- **마지막 질문은 말할 시간을 남긴다.** 피드백을 받으려는 발표라서 이 질문을 못 하면 의미가 줄어든다.
- **5분을 넘으면** 2장 첫 문단의 예산 · 법률 문장, 3장의 R3 275개 설명 순으로 줄인다.

| n이 왜 18인가? | `880730`이 HS2022 신설 코드라 2016~20 값이 없어 제외했다. 13개 기준에서는 같은 이유로 n=12 |
| ρ=0.97은 당연한 것 아닌가? | 맞다. HHI에 1위국 점유율의 제곱이 들어간다. 그래서 중복 지표로 판정하고 화면에는 하나만 쓰기로 했다 |
| 0.85 → 0.05는 어떤 상관인가? | Pearson(반도체 월 수입액 × 전자부품 생산지수). 둘 다 오르는 추세라 수준 상관이 높게 나왔고, 전년동월비로 추세를 걷어내면 사라진다 |

### 데이터 명세 (7장)

| 질문 | 답 |
|---|---|
| 명세서 형식은 제출 양식에 맞나? | 드라이브 샘플 `3_데이터수집목록및명세서_샘플.xlsx`를 참고했다. 「목록」 시트(데이터명·크기·개수·유형·제공처) + 데이터셋별 명세 시트(컬럼명 영문·한글·Data Type·예시값·비고) 구성이 같다 |
| 개수는 어떻게 센 것인가? | 포털 표시 건수를 옮긴 게 아니다. 내려받은 원본을 파서로 세고, RDS 적재 후 `COUNT(*)`로 다시 세서 두 값이 맞는지 확인했다. 포털 표시와 다른 경우(국내조달 계약정보 43,112 vs 포털 48,821)는 차이를 기록만 하고 원인 미확인으로 남겼다 |
| 컬럼 441개는 원본 열만인가? | 원본 열 + 적재·파생 열(행 ID·원본 파일명·원본 행 번호·적재 시각 등)을 모두 실었고, 원본에 없는 열은 「(적재)」·「(파생)」으로 구분했다. 시트 끝에 「원본 열 n + 적재·파생 열 m」으로 집계해 뒀다 |
| 예시값이 실제 데이터인가? | RDS에서 뽑은 실제 값이다. 단 담당자명·대표자명·사업자번호·주소 같은 개인정보성 열은 「예시 생략(개인정보)」으로 바꿨다 |
| 정제하면서 버린 열이 있나? | 지운 열은 없다. 정제층에 옮기지 않은 열은 원본(`raw_`)에 그대로 있고, 「정제변경_상세」 시트에 열마다 6유형(동일명 유지 / 타입 변경 / 이름 변경 / 파생 추가 / 미적재(업무열) / 미적재(추적 메타))으로 528행을 적었다 |
| 명세서를 손으로 만들었나? | 아니다. `scripts/gen_data_spec_xlsx.py`가 `meta_dataset`(출처·확보 기록)·열 사전·RDS `information_schema`에서 만든다. 제출 직전에 다시 돌리면 그 시점 DB와 일치한다 |
| DB에는 표가 몇 개인가? | 표 56 · 뷰 31. 접두어별 역할·행 수·열 수는 「(참고) DB 테이블·뷰」 시트에 전부 실려 있고, ERD는 `docs/db/erd.html`로 따로 있다 |
