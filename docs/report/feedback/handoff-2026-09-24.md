## 2. 결정 필요 — 적용장비 이름을 실을까

- `app/specs/21_parts_fsc.md` §4에는 「적용장비 상위 20(09-23 추가 · 구현 전)」 행이 있는데, 같은 문서 §7 · 페이지 코드(`app/pages/2_부품_무기체계.py` 머리 주석)는 **「적용장비는 이름 없이 종류 수만」**(`docs/idea-review.md` §3-10 — 특정 무기체계의 취약 부품 특정 금지)이라 서로 부딪힌다.
- **조장 의견**: 금지선은 「적용장비명 × 부품번호」 조합으로 취약 부품을 짚는 것이다. **장비 이름별 품목 건수만**(부품번호 · FSC와 조합 없이, 필터로도 쓰지 않음) 보이는 것은 그 선을 넘지 않는다고 본다 → (a) 싣기를 제안. 예) 레이더 세트 129건 중 전자 군급 92건. 「미상」 2,018행은 막대에서 빼고 캡션.
- 훈희 판단이 (b) 빼기면 알려 주면 기획서 v6에서 핵심 5개 → 4개로 줄인다.
