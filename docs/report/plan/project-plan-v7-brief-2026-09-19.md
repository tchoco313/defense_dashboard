## 1. 주제

**주요 방산 전자부품 수입 의존도 및 국산화 현황 모니터링 대시보드** — 법령·분류코드 근거로 고른 전자부품 품목군이 어느 나라에서 들어오고, 어떤 무기체계에 쓰이며, 국산화는 어디까지 왔는지를 부품 관점에서 한 흐름으로 보여 주는 현황 대시보드.

- 「수입 의존도」 = 품목군 수입액 중 특정 국가 비중(상위 1개국 점유율 · HHI). 자급률은 자료가 없어 산출하지 않는다.
- **핵심 질문**: 어떤 방산 관련 전자부품이 어느 나라에 얼마나 의존하고, 그 부품은 어떤 무기체계에 쓰이며, 국산화 개발은 어디까지 와 있는가.
- **하지 않는 것**: 미래 위험 예측 · 위험 지수 / 국산화율 · 국산화 우선순위 확정 / 군 직접 수입 비율 확정(하한 추정만) / 예산과 수입 변화의 인과 판단.

## 3. 타겟

방산 전자부품의 해외 의존 현황을 **공개 자료로 확인하고 인용해야 하는 사람**.

| 층 | 지금 쓰는 수단 → 이 도구 |
|---|---|
| 정책 · 예산(국회 의원실 · 입법조사처 · 예산정책처, 국방 예산 · 정책 기획) | 부처 자료요구 · 내부 보고자료 → 출처 · 기준일이 붙은 공개 수치로 교차 확인 |
| 연구 · 분석(연구기관 · 학계 · 언론) | 무역통계 포털 직접 조회 → 법령 근거 품목군 기준선을 매년 같은 기준으로 비교 |
| 산업 · 참여(방산 중소 · 벤처) | 공고 과제명만 확인 → 군급 · 적용장비 · 국산화 이력을 한 화면에서 탐색 |

내부 자료로 국산화 과제를 확정하는 업무는 범위 밖. 방위사업청 공급망 분석 · 조기 경보시스템과 발전전략의 공급망 정보체계는 내부용이라는 점이 이 도구의 자리다(「내부용」은 추론 — 걸리면 「공개 계획은 문서에 없다」로 낮춘다).

## 4. 분석 대상

**수입 측 — 품목군(HS 6단위) 19개.** HS 84 · 85 · 88 · 90류 6단위 1,003개 전부에 규칙 적용.

| 규칙 | 내용 | 근거 자료 |
|---|---|---|
| R1 군용 전용 | 하위 10단위에 「군용 무기 · 유도탄 전용」 세분류 | 관세청 HS부호(15049722) · 품목명(15130660) |
| R2 전문 용도 | 항공기용 · 항행 · 레이더 · 무인기 용도가 품목명에 명시 | 같음 |
| R3 전략물자 | 이중용도 통제번호(전자 · 정보통신 · 센서 · 항법) 연계 | 무역안보관리원 HSK 연계표(15034135) |
| R4 국산화 이력 | 대응 군급에 국산화개발품목이 있음 | 방위사업청 국산화개발품목(15119899) |

- 1단계 「R1 또는 R2 또는 (R3 그리고 R4)」 통과 **58개** → 2단계 무기체계 전자 계열만 남겨 **19개** = 전자 · 항법 계열 17 + 항공 분야 비교용 2(터보제트 부분품 · 항공기 부분품).
- 제외 39개 = 84류 27(엔진 · 펌프 · 여과기 · 베어링 등) + 점화 · 시동 · 배선 8 + 자동조절기기 4.
- 관세청 **수집은 24개**(분석 19 + 규칙 미해당 5 — DATA INFO에 이유 표시).
- 교차 확인: 방위사업청 7대 유형 중 5개 유형이 반도체 계열 품목군 6개와 대응. 센서 유형은 19개에 없고 우주 · 극한 유형은 HS로 구분되지 않는다. **유형↔HS 대응은 팀 판단** — 범례로만 쓰고 유형별 수입액을 합산하지 않는다.
- R2 품목 민 · 군 구분: 관세청 시군구별 수입에서 **과천 수입자 비중 = 군 직접 수입의 하한(추정)**. 2025년 항공 · 항법 · 통신 10~30%, 반도체 0%대.

**군수품 측 — 군급 FSG 58 · 59 · 60.** HS와 FSC는 공식 연계표가 없어 **직접 결합 · 합산하지 않고** 품목 계열 수준에서 나란히 놓는다.
