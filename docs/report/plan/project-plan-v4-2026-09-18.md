## 프로젝트 기획안(데이터 중심 국방 대시보드 제작 프로젝트)

작성일자 : 2026년 9월 18일

**조 명** : 훈수안이조
**조 원** : 조장: 안태호 / 조원: 강지수, 김훈희, 이동현, 조수아

---

### 프로젝트 주제

**주요 방산 전자부품 수입 의존도 및 국산화 현황 모니터링 대시보드**
— 법령·분류코드 근거로 선정한 전자부품 품목군의 국가별 수입 의존도, 해당 부품이 쓰이는 무기체계(적용장비), 국산화 개발 현황을 부품 관점에서 한 흐름으로 확인. 군 직접 수입 추정과 수출·국내 생산 기반은 해석을 돕는 보조 근거로 함께 제시

---

### 프로젝트 개요

**- 배경**

① **국방 전자부품의 해외 의존은 확인된 문제**
→ 무기체계 첨단 반도체 98.9% 해외 의존, 전원용 99.5% · 메모리 98.8% · GaN 제조 100% 해외 파운드리(방위사업청 의뢰 연구, 언론 재인용) [13]

② **정책·예산은 지금 확대 중**
→ 「국방반도체 육성 및 지원에 관한 법률」 제정(법률 제21762호, 2026-06-09 공포, 2026-12-10 시행) [14], 방위사업청 100대 국방반도체 핵심과제 로드맵 연말 확정 예정 [15]
→ 국방기술개발 예산 2020년 1조 53억 원 → 2027년 정부안 3조 741억 원(3.06배), 2027년 국방반도체 R&D 565.1억 원 신설 [9]

**- 필요성**

□ **부품 단위 현황을 볼 공개 도구가 없음**
정책이 부품 국산화로 향하고 있지만 「어떤 부품이 · 어느 나라에 · 얼마나 의존하는가」를 부품 기준으로 모아 보여주는 공개 도구는 없음. 국외조달 조달계획(2017~2025년 3,029건 · 18.26조 원)에는 공급 국가가 없고 [7], 관세청 수입 통계에는 국방 구분이 없음 [1]

□ **자료가 4개 기관 · 2개 코드체계로 흩어져 있음**
수입(관세청, HS 코드) · 조달·국산화(방위사업청, 군급 FSC 코드) · 국산화 과제(국방기술진흥연구소) · 예산(열린재정). 부품 하나를 보려면 기관별로 조회해 코드를 맞추고 다시 집계해야 함

□ **포털 통계를 그대로 옮기면 국방과 연결되지 않음**
관세청 통계는 민항·조선·자동차 수요가 섞인 국가 전체 수입. 부품 선정 근거(법령·분류코드), 무기체계 연결(적용장비), 민·군 구분(수입자 지역)을 덧붙여야 국방 관점의 현황이 됨
→ 확인: 분석 대상 19개 품목군 2025년 수입 499억 달러 중 7개가 특정국 50% 이상 의존 — 항공·항법은 미국(73%·76%), 반도체는 대만·중국(55%·58%) [1][19]
→ 확인: 같은 계열 부품이 쓰이는 장비는 국외 조달계획 「적용장비명」으로 연결 가능 — 전자·통신 군급 2,270건, 적용장비 365종 [6][19]

□ **「수출 강국」 합계만 보면 의존이 가려짐**
반도체 · 통신 부분품은 HS 합계로 수출이 수입보다 크지만(프로세서 IC 수출/수입 1.09배, 통신·레이더 부분품 4.70배), 대부분 민수 제품. 반대로 항공 항행기기 · 광학기기 · 레이더는 수입이 수출의 약 3~7배 [1][19] → 품목군별로 나눠 봐야 국방 전자부품의 의존 구조가 보임

**- 목적**

□ **핵심 질문**: 어떤 방산 관련 전자부품이 어느 나라에 얼마나 의존하고, 그 부품은 어떤 무기체계에 쓰이며, 국산화 개발은 어디까지 와 있는가
□ **산출물**: 수입 의존도 · 부품→무기체계(국산화 이력 포함) · 품목군 현황표 · 정책·산업 배경을 탭으로 연결한 현황 모니터링 대시보드(Streamlit, 홈 + 5탭)
□ **범위 제외(결과 해석 범위)**: 미래 위험 예측 · 위험 지수 산출 / 1~2차 협력업체 간 원자재 흐름 / 기업별 부품 사용 내역 / 국산화율 산출 · 국산화 우선순위 확정 / 예산과 수입 변화의 인과 판단

**- 분석 대상 및 범위**

□ **수입 측: 전자부품 품목군(관세청 HS 6단위) — 공식 분류·법령 자료에 2단계 규칙을 적용해 선정**
HS 84·85·88·90류 HS6 1,003개 전체에 R1~R4 적용 [2][3][4]
→ **R1 군용 전용**: 하위 HSK 10단위에 「제9301호(군용 무기)·제9306호(폭탄·유도탄·탄약)의 물품에 전용」 세분류 존재 — 관세법 제84조 → 관세·통계통합품목분류표 [2]
→ **R2 전문용도(민수 포함)**: 하위 HSK 또는 HS6 명칭에 항공기용·항행·레이더·무인기 용도 명시 — 근거 같음 [2]. 민항·조선·자동차 수요를 포함하므로 수입자 지역으로 「군 직접 수입(하한)」과 「민수 확인」분을 별도 표시 [20]
→ **R3 전략물자**: 하위 HSK가 이중용도 통제번호 3부(전자)·5부(정보통신)·6부(센서·레이저)·7부(항법·항공전자)와 연계 — 대외무역법 제19조 → 전략물자수출입고시 별표2 [3]
→ **R4 국산화 이력**: 대응 군급(FSC)에 방위사업청 국산화개발품목 존재 — 무기체계 부품국산화개발 관리규정(방위사업청 훈령 제983호) [4][16]
→ **1단계 선정식** R1 또는 R2 또는 (R3 그리고 R4) → 1,003개 중 **58개** 충족. R3는 범위가 넓어(이중용도 연계 HS6 275개) 단독 선정 없음
→ **2단계 계열 한정** 무기체계 전자 계열(반도체 · 레이더 · 통신 · 항법 · 항공전자 · 전자광학)에 해당하는 품목군만 남김. 「항공기용」 세분류 때문에 R2에 걸린 엔진·펌프·필터·베어링(84류), 엔진 점화 전장품(8511·854430), 자동조절기기(9032) 등 **39개 제외**
→ **결과 19개 = 분석 대상**(전자부품 계열 17 + 항공 부분품 2는 비교용). 항공 부분품 2개(841191 · 880730)는 군·민항 정비 수요가 섞인 항공 계열의 비교 기준으로만 두고(전자부품 지표·KPI와 분리 표시), 완제품 엔진(841111 · 841112 등)은 두지 않음. 수집 24개 중 규칙 미충족 5개는 「근거 미확인」으로 수집만 유지. 목록은 **[별표 1]**
※ 자료와 법령은 공식, 규칙 조합과 2단계 계열 한정은 팀 분석 규칙(DB에 버전별 저장). 정부의 공식 「방산 전자부품 목록」이 아님

□ **군수품 측: 군급 FSG 58 · 59 · 60**(통신·탐지 장비 / 전기·전자 구성품 / 광섬유) — 미 국방안보협력국(DSCA) SAMM Appendix 4의 H6 항목이 FSG 58XX·59XX·60XX를 직접 지정 [11]. 코드·명칭은 DLA 분류표·방위사업청 군급분류집으로 확인 [5][12]

□ **두 분류체계의 관계**: HS와 FSC는 공식 연계표가 없어 직접 결합·합산하지 않음. 품목 계열(반도체·레이더·통신·항법·전자광학) 수준에서 나란히 배치

**- 타겟 (사용자 범위)**

□ **공통 조건**: 방산 전자부품의 해외 의존 현황을 **공개 자료로 확인·인용해야 하는 사람**. 흩어진 공개 자료를 부품 기준으로 묶은 수치를 출처·기준일·한계와 함께 가져다 쓰는 용도
□ **범위 밖**: 내부 BOM · 원산지 · 재고 DB로 국산화 과제를 **확정하는** 업무, 대기업 구매팀의 자사 공급망 관리. 방위사업청 내부 공급망 분석 · 조기 경보시스템(2025-12 업무보고 발표) [25]과 경쟁하지 않음

→ **정책·예산 그룹** — 국회(의원실 · 입법조사처 · 예산정책처), 방위사업청 · 국방기술진흥연구소 기획 부서
　지금: 필요할 때마다 부처에 자료요구 → 건별 대기, 요구마다 기준이 다름 [22]
　쓰는 장면: 대외 보고 · 국회 답변 때 공개 수치로 교차 확인 → 홈 · ① · ③ · ④

→ **연구·분석 그룹** — 국방 · 산업 연구기관, 학계, 언론
　지금: 보고서마다 실태조사 · 직접 수집, 기존 연구는 소재 중심이라 전자부품 공백 [23]
　쓰는 장면: 보고서 · 기사의 기준선 수치, 매년 같은 기준으로 비교 → ① · ② · ③ · ⑤

→ **산업·참여 그룹** — 방산 중소 · 벤처기업
　지금: 국방기술진흥연구소 공고의 과제명만 확인 → 그 부품이 어떤 장비에 쓰이는지, 해외 조달 수요가 얼마인지 알기 어려움 [10][24]
　쓰는 장면: 과제 참여 전 적용장비 · 국외 조달 수요 · 국산화 이력 · 국내 생산 기반 탐색 → ② · ④

**- 기대효과**

□ **정책·예산 · 연구 그룹 — 자료요구 · 개별 수집 없이 인용**: 4개 기관 공개자료를 부품(품목군 · 군급) 기준으로 묶은 수치를 출처 · 기준일과 함께 바로 인용
□ **같은 기준의 매년 비교**: 상위 1개국 점유율 · HHI를 같은 규칙 · 같은 기간 기준(2025 / 5년 / 전체)으로 비교 → 정책 전후 의존 구조 변화 확인
□ **산업 그룹 — 부품–무기체계–국산화 연계 확인**: 과제명만으로 알 수 없던 적용장비 · 국외 조달 수요 · 국산화 개발 이력을 한 화면에서 확인
□ **근거가 남는 공개자료 분석**: 선정 근거 · 민군 구분(군 직접 수입 추정) 방법 · 자료 한계를 화면에 명시 → 인용하는 사람이 한계까지 함께 인용

**2. 데이터 전처리 — 탭(테마)별 방향**

□ **공통**: 원본 동결 · 정제본 분리, 단계별 건수를 적재 기록에 남김. 부분연도(2026)·정부안(2027) 라벨. 개인정보(담당자명 등) 열은 정제본에 넣지 않음
□ **① 수입 의존도**: 관세청 세부코드를 품목군(HS6) · 국가 · 월/연 단위로 집계, 수출액 병행 집계. 수입자 지역은 시군구 → 지역 성격(군 직접 · 민항·조선 · 겸업·기타)으로 분류
□ **② 부품 → 무기체계**: 재고번호에서 군급(FSC) 추출, 전자·통신 범위(FSG 58·59·60)만 선별, 적용장비명 표기 통일(전자·통신 약 365종 우선). 국산화개발품목 중복 제거 후 군급 기준으로 부품 · 사업 수 집계
□ **③ 품목군 현황표**: 선정 규칙(R1~R4, 2단계) · 의존도 지표 · 수출/수입 비율 · 민군 구분 값을 품목군 한 행으로 병합
□ **④ 정책·산업 배경**: 예산 단위 통일(천원 → 억원), 2027 국회 확정액은 미확정으로 표시(0원 아님), 사업명 개편 구간은 상위 사업 합계로 연결. 가동률 · 생산지수는 가로형 → 세로형 변환, 잠정치 표시

**3. 데이터 모델링(ERD)**

□ AWS RDS MySQL 8.4(운영 DB). 원본(raw_) → 참조·규칙(ref_) → 정제(clean_ · dim_/fact_) → 화면용 집계 뷰(v_), 출처·건수는 meta_
□ 두 축 구조: ① 수입 의존도 축(HS 코드, 품목군 → 세부코드 → 월별 수출입 ← 국가, 수입자 지역) / ② 군수품·국산화 축(FSG → FSC → 국산화개발품목 · NSN · 국외 조달계획). 두 축은 공식 연계표가 없어 직접 결합하지 않음. 정책·산업 배경 자료는 연도 기준 독립 테이블
□ 다이어그램은 **[그림 1] ERD**

**4. 분석 — 기준과 기간**

□ **분석 단위**: 품목군(HS6) · 국가 · 군급(FSC) · 군(육·해·공) · 수입자 지역
□ **기간 기준 3단** (모든 지표를 같은 3단으로 전환해 비교)
→ **기준 연도** 2025년(최근 완결 연도) — 현재 상태
→ **최근 5년** 2021~2025년 — 추세, 1위 공급국 교체 여부
→ **전체** 2016~2026.08 — 장기 변화 (2026은 부분연도 표시)

□ **분석 질문과 방법**
→ 어느 나라에 얼마나 의존하나: 상위 1개국 점유율 · HHI(Σ점유율²) · 교역국 수, 50% 참고선(산업부 3050 기준 [17]) — 기준 연도 / 5년 / 전체, ① · ③ · 홈
→ 의존 구조가 바뀌었나: 1위 공급국 교체 시점, 점유율 변화, 19개 품목군 대응 비교(윌콕슨 부호순위) — 5년 / 전체, ①
→ 큰 품목일수록 더 쏠렸나: 품목군별 수입액 × HHI 순위상관(스피어만) — 기준 연도, ③
→ 수출이 크면 의존이 약한가(보조): 품목군별 수출/수입 비율 — 기준 연도, ③ (HS 합계라 민수 포함임을 명시)
→ 수입 중 군 몫은(보조): 수입자 지역 구성 — 군 직접(과천, 하한) · 민수 확인 · 판별 불가 — 기준 연도, ① 하단 · ③
→ 부품이 어디에 쓰이나: 군급 × 적용장비 빈도, 여러 장비에 공통으로 쓰이는 부품군 식별 — 5년 / 전체, ②
→ 군별로 다른가: 육·해·공별 전자·통신 군급 비중 차이(카이제곱, 공군 표본 적음 표시) — 전체, ②
→ 국산화는 어디까지: 군급별 국산화개발 부품 · 사업 수와 국외 조달계획 건수 병렬 비교(차이·비율 계산 없음) — 확보 시점 기준, ② 하단
→ 국내 기반은(보조): 통신전자 가동률 추이 · 전자부품 생산지수(2020=100) — 연 / 월, ④ (수입 변화와 인과로 해석하지 않음)

**5. 시각화 — 탭별 화면 구성(상단 · 중앙 · 하단)**

□ **홈**
　상단: KPI 카드 5 — 분석 품목군 19 · 2025 수입 499억 달러 · 특정국 50% 이상 7 · 전자·통신 조달계획 2,270건/적용장비 365종 · 국산화개발 부품 수
　중앙: 세계지도(국가별 수입액) + 품목군별 1위 공급국 요약 막대
　하단: 탭 안내, 데이터 기준일, 「국가 전체 수입(민수 포함) · 군 직접 수입은 추정(하한)」 고지

□ **① 수입 의존도**
　상단: 필터(품목군 · 기간 기준 2025/5년/전체) · KPI(수입액 · 1위국 점유율 · HHI · 교역국 수)
　중앙: 연도별 국가 구성 100% 누적막대(50% 참고선) + 월별 수입액 추이(수출 선 켜기/끄기)
　하단: 국가별 수입액 표 · 세부코드(HS10) 상세 · **수입자 지역 구성(군 직접 하한 / 민수 확인)**

□ **② 부품 → 무기체계**
　상단: 필터(군급 · 군 · 기간) · KPI(조달계획 건수 · 적용장비 수 · 국산화개발 부품 수)
　중앙: 군급 × 적용장비 히트맵, 선택 군급의 적용장비 목록
　하단: **국산화 패널** — 군급별 국산화개발 부품 수 ↔ 국외 조달계획 건수 병렬 막대, 사업명 ↔ 적용장비명 표, 「확보 목록 기준, 국산화율 아님」 라벨. 장비 선택 시 역조회(이 장비에 들어가는 전자부품군)

□ **③ 품목군 현황표**
　상단: 정렬 · 필터(계열 · 선정 근거 · 50% 이상 여부)
　중앙: 19개 품목군 표 — 선정 근거 · 수입액 · 1위국 · 점유율 · HHI · 수출/수입 비율 · 군 직접(하한) · 민수 확인 · 관련 군급 이력
　하단: 수입액 × HHI 산점도 · CSV 내려받기

□ **④ 정책·산업 배경**
　상단: KPI(국방기술개발 · 국방반도체 예산 2027 정부안 · 통신전자 가동률 · 통신전자 지정 방산업체 수)
　중앙: 예산 추이 선(국방기술개발 · 부품국산화 · 국방반도체), 국외조달 계획 예산 집행유형 누적막대(계획 기준 · 국가 없음)
　하단: **국내 생산 기반 패널** — 분야별 가동률 추이, 전자부품 생산지수(2020=100)

□ **⑤ DATA INFO**
　데이터 출처 · 기간 · 기준일, 선정 규칙(1·2단계) · 군 직접 수입 판별 방법 · 단계별 건수, 쓰지 않은 데이터와 이유, 자료별 한계(민수 포함 · 계획≠계약 · 국산화율 아님 · 과천 = 추정 하한)

□ 색 약속: 색은 국가·계열 구분용, 의존도는 단일 색 농도. 위험·정상 의미의 빨강·초록, 3D · 게이지 사용 안 함
