## 0. 원칙

1. **세고 · 나누고 · 보여 준다.** 합계 · 비율 · 순위 · 지수 · 변동계수 · 점유율 · HHI까지. 검정 · 상관계수는 노트북에만 두고 결론 · 발표 · 화면에 쓰지 않는다.
2. **기간 3단 + YTD**: 2025(기준) · 2021~2025(최근 5년) · 2016~2026.08(전체). 2026은 연간 비교 대신 1~8월끼리 비교한다.
3. **라벨 고정**: 관세청 값은 「국가 전체 교역(민수 포함)」. HHI · Top1 · CR3 · CV는 위험도가 아니다. 건수는 국산화율이 아니다.
4. **단위**: 국가 fact는 USD, 시군구는 천 USD — 섞을 때는 환산을 적는다. 달러와 원화는 합산하지 않는다.
5. **HS 축과 FSC 축은 JOIN하지 않는다.** 두 자료의 구성을 나란히 놓는 것까지만.
6. **분석마다 기록**: 질문 · 기준 테이블 · 분석 단위 · N · 필터 · 산식 · 단위 · 해석 한 줄 · 한계. 검정이면 외부 초안 §12 양식(H0/H1 · 통계량 · 효과크기)을 더한다.
