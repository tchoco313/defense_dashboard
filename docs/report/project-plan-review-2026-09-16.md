## 3. 팀이 확인할 것

- **9/25 진도 점검·9/28 시연 예비 녹화**: PROJECT.md에 없는 팀 내부 일정. 수행 가이드 달력에는 9/24·9/25가 수업일에 없다(추석 연휴로 추정) — 온라인 점검이면 그대로, 아니면 9/23으로 당길지 결정. 사용자 결정으로 날짜는 유지했다.
- **분석 대상 19개의 소재장비 2개**: 팀 우선순위 1·2에 든 841191(터보제트 부분품)·880730(항공기 부분품)을 `hs-whitelist-definition.md`는 "배경 자료(분석 대상 아님)"로 적는다. 9/18 안건(부품/설비 구분)에서 확정하고 19 또는 17로 통일할 것.
- **`docs/data-sources.md:12,54`**: 국외조달 계약정보 파일 ID를 "미확인"에서 `15050924`로 갱신. 국외 조달계획·입찰결과 파일판 ID는 여전히 미확인.
- **DBMS 표기**: 기획서·PROJECT.md는 "MySQL 8.4"(팀 서버 실측 `VERSION()` 8.4.11), CLAUDE.md·런북 §0은 "MariaDB 확정". 제출 문서는 MySQL로 통일했고 내부 문서 표기는 별도 정리 필요.
- **저장소 문서 구버전 수치**(기획서는 최신값과 일치): `schema-design.md` §1(raw 18·ref 7·뷰 15·열 사전 281·clean 3,024), `table-guide.md` §1(raw 18·ref 7·뷰 14·열 사전 219·load_log 37).

## 4. 이번 세션에 재조회하지 못한 `[DB]` 수치

DBHub 연결 실패로 아래는 v8 부록 B(2026-09-16 19시 팀 DB 검증)의 값을 그대로 썼다. 다음 세션에 `v_import_hs6_year`·`v_hhi_hs6_year`·`raw_dapa_contract`·`raw_dapa_overseas_contract`로 재조회할 것.

- 2025 수입액 681억$(24개) / 499억$(19개), 상위국 대만 33.9%·일본 14.7%·미국 10.6% / 대만 45.4%·일본 12.9%·중국 10.8%
- 854231 336억$·대만 55.4%·HHI 3,493 / 852990 3,142 / 852910 1,870 / 안테나 2024→2025 3,665→1,870(미국 56.9% → 베트남 30.9%) — 마지막 항목은 v8 본문에만 있고 부록 B 검증표에는 없음
- χ² 5,982, 수의계약 70.2%(30,255/43,112) vs 20.1%(1,276/6,333) — `docs/`에 기록 없음, v8에서만
- 열린재정 10,053.3 → 30,741.4억, 565.1억, 7.5 → 55.5억 — `data-sources.md:97`와 일치
