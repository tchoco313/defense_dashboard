# 데이터 사용 결정표 — 화면 구상 기준 (2026-09-18)

9/18 회의 방향: **데이터를 무엇을 쓸지 먼저 정하고 그에 맞게 화면을 구상**한다. 이 표에서 판정(핵심 / 보조 / 제외 / 확인 필요)을 확정하면 화면 구성은 §4처럼 따라 나온다. `💬 Claude 의견`은 참고용이고, **결정** 칸은 팀이 채운다.

> 행 수·지표 값은 2026-09-18 팀 서버(백업) 조회값이다. 같은 날 RDS 전환 직후라 RDS 검증값(`docs/runbook/aws-rds-setup.md` §7)과 같지만, 확정 전 RDS에서 다시 확인한다.
