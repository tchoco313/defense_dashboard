# 대표 화면 ① 디자인 값 대비 검사 (2026-09-23)

값의 정본은 `app/mockup/common.css`. 검사 도구는 `dataviz` 스킬 `scripts/validate_palette.js`(OKLab ΔE×100, 색각 이상 시뮬레이션)와 WCAG 명도 대비. 기준: 색각 이상 ΔE ≥ 8(6~8은 직접 라벨·간격 같은 2차 부호가 있을 때만 허용), 정상 시각 ΔE ≥ 15, 시리즈 색은 배경 대비 3:1 이상.

## 3. 국가 색 (100% 누적 구성 차트, 5개국 + 기타)

전체 7개국을 한 번에 통과시키는 조합은 없었다(색각 이상 축에서 초록·자홍, 올리브·금색이 겹친다). 같은 국가 = 같은 색 원칙을 지키면서 **차트별로 실제 같이 나오는 5개 조합**을 검증했다.

| 차트 | 국가(색 이름) | 최악 쌍 | 판정 |
|---|---|---|---|
| 수입 구성 | 대만 보라 · 중국 자홍 · 일본 금색 · 미국 연보라 · 싱가포르 청록 | 중국 ↔ 싱가포르 색각 이상 ΔE 7.1 | 통과(6~8 구간 — 조각 라벨·2px 간격으로 보완), 정상 ΔE 최소 13.1 이상 |
| 수출 구성 | 중국 자홍 · 베트남 갈색 · 대만 보라 · 싱가포르 청록 · 홍콩 올리브 | 중국 ↔ 싱가포르 7.1 · 홍콩 배경 대비 2.8:1 | 통과(같은 보완). 홍콩은 조각 라벨 필수 |

추가 국가 4색(`--c-x1`~`--c-x4`)은 단일 품목군을 골랐을 때만 등장하며 모든 조합을 검증하지 않았다(미확인). 상태색(ok·warn)과 잠정 배지색은 차트에 쓰지 않는다.

## 4. 남은 것

- 국가 색은 5개+기타 조합에서만 검증됐다. 상위 국가 수를 늘려도 구성 차트는 5개+기타로 고정이므로 영향 없음.
- 실제 화면 캡처 기준 색각 시뮬레이션은 하지 않았다(수치 검증만).
