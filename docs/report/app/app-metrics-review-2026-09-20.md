# 앱 지표·설명 정합 검토 — 판정 · 수정 · 검증 · 남은 사항 (2026-09-20)

**범위**: 페이지 구조가 바뀌어도 유지돼야 할 것(데이터 정의·모집단·집계 산식·출처·설명·오류 처리)만 고쳤다. 메뉴·페이지 분리·디자인·브랜드 부제는 손대지 않았고, 운영 DB·원본·계정도 바꾸지 않았다(DB 변경은 제안 파일). 실측은 2026-09-20 RDS(DBHub app_ro)와 앱 조회 경로(`.venv`, 읽기)로 했다. 팀 확정 전 문서(기획서 v7·범위 축소안·회의 안건)는 제안으로만 다뤘다.

## 4. 남은 사항

**지금 해결할 데이터·로직 문제**

- 뷰 `share` DECIMAL 4자리 반올림 → 뷰 HHI와 pandas/EDA HHI가 최대 0.7점 차이. `CAST(... AS DOUBLE)`로 없앨 수 있음(뷰 2개 정의 변경, 제안 헤더에 기록).
- `clean_kdsis_nsn.is_electronic_group`은 여전히 58·59 기준(FSG 60 317행 누락, P5 영역·잠정) — 조회 표라 화면 영향 없으나 정의 불일치.
- `db/table_dict.csv`(다른 세션 미커밋)의 `v_hhi_hs6_year` role "국가 수"는 alter 적용 시 "수입 실적(>0) 국가 수"로 고치고 카탈로그 재생성.

**팀 결정 사항**

1. 국외조달계획 전자 판정(FSG 58·59·60 + 영숫자 NSN) 확정 여부 — 확정되면 앱·⑤의 「잠정」 표시를 뗀다.
2. 과천시 소재 수입자 비중 채택·시군구별 수입 RDS 적재 여부 — 채택 시에도 "관측값 + 가설"로만, 하한 표현 금지(`data-sources.md` 기준).
3. `v_hhi_*` `country_count` alter 적용 여부(`v_review_list` 의미도 바뀜).
4. 19개 표기(「17 + 항공 비교용 2」 vs priority 1·2), R4 잠정 6개의 잔류(2025 수입 $2.07B = 19개의 4.1%, 1위≥50% 2/7, HHI>2,500 3/10; 2021~25 $10.34B vs 나머지 13개 $216.60B) — 제외해도 요약 결론(1위≥50% 5/13, HHI>2,500 7/13)은 유지되나 통신·반도체 소자 품목군이 빠진다.
5. 제목·주 타겟(v7 vs 09-17), 국내조달 계약의 역할 — 앱은 어느 쪽도 확정하지 않은 상태.

**페이지 재구성 때 반영할 사항**

- 공통 계층을 그대로 쓴다: 집중도는 `metrics.concentration`(기간 합산) 또는 뷰(단일 연도) 중 하나를 고르고 라벨에 어느 쪽인지 적는다. 건수 KPI는 `try_query`+`count_state`(캐시 밖), 기간 선택은 `period_control(key=페이지별)`, CSV는 `csv_header` + `data_stamp(dataset_key, table)`.
- 브랜드 부제 "법령·분류코드로 고른 …"(`ui.py`)은 제목 영역이라 두었다 — 재구성 때 "공식 분류·통제표에 팀 규칙을 적용해 고른"으로 바꿀지 결정.
- "국가 수"는 항상 실적>0 기준으로 세고 "수입국 수/수출국 수"로 부른다. "교역국 수"는 쓰지 않는다.
- ①의 연도별 HHI(뷰)와 홈·③·🔎의 기간 합산 HHI를 한 화면에 둘 때는 두 지표임을 표시한다.
- 미실행 EDA(2021 vs 2025 HHI 윌콕슨, 육·해·공 χ², B2·조달계획 EDA)는 화면 문구가 "검정했다"고 말하지 않도록 유지.
