# 설계 타당성 검토 — 예산 비교군·HS6 분류 근거·"방산 수입의존도" 논리 (2026-09-15)

교수 Q&A 대비용 반론 세 가지에 답한다. 근거는 **확인됨 / 추론 / 제안 / 미확인**으로 구분하고, 확인된 수치는 기준 문서(`docs/idea-review.md`, `docs/report/professor-feedback-2026-09-15.md`, `docs/reference/hs-whitelist-definition.md`)의 값을 그대로 쓴다. 외부 조사(§4)는 2026-09-15 웹에서 직접 확인한 범위만 적고, 확인하지 못한 것은 미확인으로 남긴다.

| 질문 | 한 줄 결론 |
|---|---|
| Q1. 예산 데이터와 비교군(방산업체에 총 조달되는 예산)을 비교 시각화할 수 있는가 | **부분 가능**. 같은 기준(계획)끼리인 국외 vs 국내 조달계획(2024~2025)은 비율까지 가능. 국외 계획 vs 총 계약집행(2017~2024)은 계획/실적이 달라 **병기만**. "방산업체에 조달되는 금액"은 계약정보 × 방산업체 지정현황 매칭으로 산출 가능하나 사용자 노트북 작업 |
| Q2. HS6 21개 분류는 왜 그렇고 타당한가 | **"근거 등급이 명시된 팀 판단"**. 공식 방산 HS 목록은 없다. 21개 중 5개는 팀판단 외 근거가 없고, 품목별 민수 혼합 정도가 극단적으로 달라 이를 열(`civil_mix`)로 드러내야 한다 |
| Q3. "방산 수입의존도 → 국산화 → 방산업체 조달"의 근거는? TV 부품 아닌가 | 지적이 **맞다**. 관세청 HS로 방산 수입의존도는 산출 불가하고 설계도 그렇게 주장하지 않는다. 논리 사슬 3개 링크 중 L1(방산도 같은 공급망)은 간접 근거, L2(집중 → 국산화 검토)는 정책 판단, L3(국산화 → 조달)은 **제도 근거 확인됨**(§4-①) |

### 2-2. 판정

- **확인됨**: 공식 "방산 부품 HS 목록"은 존재하지 않는다(`idea-review.md` §2 C). 21개는 무기체계 계열(`system_family`) 기준 팀 판단이며, 타당성 근거는 "B2·KRIT·A7 자료에 같은 계열이 등장한다"는 **간접 근거**다.
- **약점(추론)**:
  1. 선정 출발점이 소버린 AI·반도체 담론(§1 원안)이라 반도체 8개가 결과론적으로 앞에 놓였다.

  3. A6 수치는 언론 인용이며 산출 기준 미확인(§4-③).
- **결론(09-15)**: "타당하다"가 아니라 **"근거 등급이 명시된 팀 판단"** 이 정직한 답이다. → (09-16) 아래 후속으로 "공식 자료 규칙 도출 + 팀 규칙 문턱값"으로 바뀜.

## 3. Q3 — "방산 수입의존도 → 국산화 → 방산업체 조달" 논리 사슬

### 3-1. 먼저 인정할 것

"이 HS 품목은 TV·가전 부품 아닌가"는 **맞다**. 관세청 HS는 용도를 구분하지 않으므로 "방산 수입의존도"는 산출할 수 없고(`idea-review.md` §2 C "국방용 반도체 수입액 — 없음", §3-3), 현 설계도 이를 측정한다고 주장하지 않는다. 대시보드가 보여 주는 것은 **"국방 관련 품목군의 국가 전체 수입(민수 포함) 집중도"** 이고, 방산 한정 수치는 A6 인용(KPI 1장)·A4 분야별 통계로만 말한다. 다만 제목("국방 핵심 전자부품 공급망 리스크")과 30초 요약은 "방산 수입의존도"로 읽힐 여지가 있어 Q&A 방어 문안이 필요하다(3-3).

### 3-2. 링크별 근거

### 3-3. 발표 답변 문안(제안)

> "맞습니다. 관세청 HS 통계는 TV·휴대폰에 들어가는 같은 품목을 함께 셉니다. 그래서 저희는 '방산 수입의존도'를 계산하지 않고, 모든 차트에 '국가 전체 수입(민수 포함)'을 붙입니다. 저희가 보여 주는 것은 두 가지를 나란히 놓은 것입니다 — ① 국방 관련 품목군의 국가 전체 공급이 어느 나라에 얼마나 쏠려 있는가(관세청), ② 그 품목군에 국방 측 근거가 있는가(국외조달 부품 예산·국산화 대상 공고·국산화 완료 목록). 방산 부품도 같은 공급망에서 조달되고, 국산화 개발품은 부품국산화개발 관리규정 §23·§24에 따라 수의계약·우선구매로 조달됩니다. 다만 '방산 부품이 민수 범용 부품과 얼마나 겹치는가'는 공개 자료로 직접 알 수 없습니다. 그래서 관세청 HS10 세분류에 용도 구분이 있는 품목군은 그 수입 비중으로 민수 혼합 정도를 계산해 붙였고 — 예를 들어 프로세서 IC 수입 중 군용 무기 전용으로 신고된 몫은 0.03%, 레이더 수입 중 항공기용은 23%입니다 — 세분류가 없는 품목군은 판단하지 않고 미확인으로 두었습니다."

### 3-4. 설계에서 바꾸지 않는 것

- "방산 수입의존도"·"국산화율"·"국방용 수입액"은 계속 쓰지 않는다(§3-3·§3-14).
- 국가 축은 관세청, 예산 축은 조달계획으로 분리하고 합산·비교하지 않는다(§3-15).
- 검토 목록은 "우선순위 확정"이 아니다.
