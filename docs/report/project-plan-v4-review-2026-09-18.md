## 4. 위험

1. **"군 직접 수입(과천) = 하한" 추정.** 관세청 시군구 통계는 신고인(납세의무자) 소재지 기준이라, 방사청 국외조달 물자가 방사청(과천) 이름으로 신고되는지, 체계업체(창원·성남·사천 등) 이름으로 신고되는지 확인된 바 없다. 후자가 많으면 "과천 비중"은 하한조차 아니다. 또 과천에는 방사청 외 다른 수입자도 있다. **검증 없이 화면에 올리면 09-17 피드백이 지적한 "근거 없는 의존도"가 다시 된다.** 제안: 9/26까지 (a) 데이터 확보·기록 (b) 88류(항공기 부분품)처럼 국외조달 비중이 큰 품목군에서 과천 수입액과 국외조달 계획 규모가 같은 자릿수인지 대조 (c) 안 맞으면 ① 하단·③ 열·홈 고지 문구에서 **삭제**. 기획서에는 "시도(실험) 항목"으로 표기.
2. **일정.** 9/22~26 정제(A8 적용장비명 365종 통일 + B2 대응표 + 시군구 적재), 9/28~30 검정 3종 + 화면 6개. 현재 구현은 ① 1장. DB 쓰기는 김훈희 1인. 제안: 화면 순서를 **④·⑤(값 있음) → 홈 → ③ → ②** 로 바꾸고 ② 역조회·①·③의 군 직접 열은 "시간 남으면"으로 내린다.
3. **2단계 계열 한정이 DB에 없다.** 기획서가 "DB에 버전별 저장"이라고 쓰므로 `ref_hs_whitelist`에 `stage2_family`(반도체·레이더·통신·항법·항공전자·전자광학·항공부분품) 열 또는 `ref_hs_rule_flag`에 `rule_version='2026-09-18'` 행이 필요. alter 1건, 훈희 님 적용.
4. **B2 사업명 ↔ A8 적용장비명 연결.** 28개 사업이라 손으로 만들 수 있지만 "K9 자주포" ↔ "K9A1"처럼 파생형 처리 기준을 정해야 하고, `ref_` 테이블로 저장해 근거를 남겨야 한다. 텍스트 자동 매칭은 금지 규칙.
5. **홈 KPI 숫자 두 개(2,270·365)가 정제 기준표(1,819)와 다르다.** 발표 전에 하나로 맞추고 산출 SQL을 [19]에 적는다.

## 5. 문구·구성 수정 제안

- 배경 ①의 "98.9% 해외 의존"은 언론 재인용 [13]이므로 v3처럼 "원문 미열람" 표기를 유지.
- "국방 전자부품의 해외 의존은 확인된 문제"는 우리 데이터로 확인한 게 아니라 인용이다 → "보고된 문제".
- 필요성 "→ 확인:" 두 줄은 미확인 수치(50% 이상 7개, 2,270건)를 담고 있으므로 DB 대조 뒤에 넣거나 "잠정" 표기.
- 범위 제외에 "군 직접 수입 비율 확정(추정 하한만 제시)"과 "국산화율" 외에 "원산지"를 추가.
- 일정 9/17~19 항목에 "시군구별 수입 데이터 확보·기록"을 넣어야 9/22 적재 항목과 이어진다.
- [11]·[20]·[21]의 URL·확보일이 없다. [19]는 "2026-09-18 조회"라 했지만 이 세션에서는 DB가 끊겨 있었으므로 조회한 사람·시각을 적는다.
- 참고자료 [22]~[25] 중 [24]는 포털 재게재라 원문 매체로 교체 예정이라고 스스로 적었다 — 제출 전 교체.
