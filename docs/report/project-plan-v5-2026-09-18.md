## 프로젝트 기획안(데이터 중심 국방 대시보드 제작 프로젝트)

작성일자 : 2026년 9월 18일

**조 명** : 훈수안이조
**조 원** : 조장 안태호 / 조원 강지수, 김훈희, 이동현, 조수아

---

### 프로젝트 주제

**주요 방산 전자부품 수입 의존도 및 국산화 현황 모니터링 대시보드**
— 법령·분류코드 근거로 고른 전자부품 품목군이 어느 나라에서 들어오고, 어떤 무기체계에 쓰이며, 국산화는 어디까지 왔는지를 부품 관점에서 한 흐름으로 보여 주는 현황 대시보드

> 이 기획서에서 「수입 의존도」는 **품목군 수입액 중 특정 국가의 비중**(상위 1개국 점유율·HHI)을 뜻한다. 국내 생산·군 소요 대비 비율(자급률·해외 의존율)은 자료가 없어 산출하지 않는다.

---

### 프로젝트 개요

**배경**

□ 무기체계용 첨단 반도체의 98.9%, 전원용 반도체의 99.5%가 해외 조달이라고 보고됐다(방위사업청 의뢰 연구, 언론 재인용) [11]. 「국방반도체 육성 및 지원에 관한 법률」이 2026-12 시행되고 [12], 국방기술개발 예산은 2020년 1조 53억 원에서 2027년 정부안 3조 741억 원으로 3.06배 늘었다 [8].
□ 그런데 「어떤 부품이 · 어느 나라에 · 얼마나」를 부품 기준으로 보여 주는 공개 도구가 없다. 국외조달 조달계획(2017~2025년 3,029건·18.26조 원)에는 공급 국가가 없고 [6], 관세청 수입 통계에는 국방 구분이 없다 [1]. 자료가 4개 기관·2개 코드체계(HS·FSC)에 흩어져 있어 부품 하나를 보려면 기관별로 조회해 코드를 맞춰야 한다.
□ 포털 통계를 그대로 옮기면 국방과 연결되지 않는다. 관세청 통계는 민항·조선·자동차 수요가 섞인 국가 전체 수입이므로, 부품 선정 근거(법령·분류코드)와 무기체계 연결(적용장비)을 덧붙여야 국방 관점의 현황이 된다. 반도체·통신 부분품은 HS 합계로는 수출이 수입보다 크지만 대부분 민수이고, 항공 항행기기·광학기기·레이더는 수입이 수출의 3~7배다(잠정) [1][19].

**목적**

□ 핵심 질문: 어떤 방산 관련 전자부품이 어느 나라에 얼마나 의존하고, 그 부품은 어떤 무기체계에 쓰이며, 국산화 개발은 어디까지 와 있는가.
□ 산출물: 수입 의존도 → 부품→무기체계(국산화 이력) → 품목군 현황표 → 정책·산업 배경을 탭으로 연결한 Streamlit 대시보드(홈 + 5탭).
□ 하지 않는 것: 미래 위험 예측·위험 지수 / 협력업체 간 원자재 흐름 / 기업별 부품 사용 내역 / 국산화율·원산지 산출 / 국산화 우선순위 확정 / 예산과 수입 변화의 인과 판단.

**분석 대상**

□ 수입 측 — 전자부품 품목군(관세청 HS 6단위) 19개. HS 84·85·88·90류 6단위 코드 1,003개 전부에 규칙을 적용해 골랐다.
　R1 군용 전용(하위 10단위에 「제9301·9306호 물품 전용」 세분류) [2] · R2 항공·항행·레이더 용도 명시 [2] · R3 전략물자 이중용도 연계 [3] · R4 대응 군급에 국산화개발 이력 [4][14].
　1단계 R1 또는 R2 또는 (R3 그리고 R4) → 58개 → 2단계 무기체계 전자 계열(반도체·레이더·통신·항법·항공전자·전자광학)만 남김 → **19개**(항공 부분품 2개는 비교용). 규칙 미충족 5개는 「근거 미확인」으로 수집만 유지. 자료·법령은 공식이나 규칙 조합은 팀 분석 규칙이며, 정부의 공식 목록이 아니다. 목록·판정값은 데이터 명세서에.
□ 군수품 측 — 군급 FSG 58·59·60(통신·탐지 / 전기·전자 구성품 / 광섬유) [5][10].
□ 두 분류체계는 공식 연계표가 없어 직접 결합·합산하지 않고, 품목 계열 수준에서 나란히 놓는다.

**타겟 (사용자 범위)**

방산 전자부품의 해외 의존 현황을 **공개 자료로 확인·인용해야 하는 사람**. 내부 BOM·원산지·재고로 국산화 과제를 확정하는 업무나 기업의 자사 공급망 관리는 범위 밖이며, 방위사업청 내부 공급망 조기경보체계 [22]와 경쟁하지 않는다.
→ 정책·예산 그룹(국회·방위사업청·국방기술진흥연구소 기획 부서): 자료요구 없이 공개 수치로 교차 확인 — 홈·①·③·④
→ 연구·분석 그룹(연구기관·학계·언론): 보고서·기사의 기준선 수치, 매년 같은 기준으로 비교 — ①·②·③·⑤
→ 산업·참여 그룹(방산 중소·벤처): 과제 참여 전 적용장비·국외 조달 수요·국산화 이력 탐색 — ②·④

---

### 기대효과

□ 4개 기관 공개자료를 부품(품목군·군급) 기준으로 묶은 수치를 출처·기준일과 함께 바로 인용할 수 있다.
□ 상위 1개국 점유율·HHI를 같은 규칙·같은 기간(2025 / 최근 5년 / 전체)으로 매년 비교할 수 있다.
□ 과제명만으로 알 수 없던 부품–무기체계–국산화 이력을 한 화면에서 확인할 수 있다.
□ 선정 근거·자료 한계를 화면에 명시해, 인용하는 사람이 한계까지 함께 인용하게 한다.

### 프로젝트 수행 방향 및 내용

**● 프로젝트 내용**

**1. 데이터 수집** — 핵심 5종은 화면의 중심 질문에, 보조 4종은 해석·배경에 쓴다. 출처·규모는 「데이터 소개」 표.
→ 핵심: 관세청 품목별 국가별 수출입실적(국가별 수입액을 주는 유일한 공식 통계) [1] · HS부호·품목명과 HSK 연계표(선정 규칙 근거) [2][3] · 국외 조달계획 품목 단위 OpenAPI(재고번호·군·**적용장비명**을 함께 주는 유일한 공개 자료) [6] · 군급분류집 [5] · 국산화개발품목(군급별 국산화 완료 이력) [4]
→ 보조: 국외조달 조달계획 파일판·열린재정 예산(정책 배경) [6][8] · 국내 생산 기반 3종(방산업체 가동률·지정현황·전자부품 생산지수) [15][16][17] · 부품국산화 공고·국방표준 NSN(과제 대상·품명 보강) [9]
→ 시도 항목: 관세청 시도·시군구별 수출입실적 [18] — 수입자 소재지로 군 직접 수입 하한을 추정하는 방법. 신고 주체 확인 등 검증이 끝나야 채택.

**2. 전처리** — 원본 동결·정제본 분리, 단계별 건수를 적재 기록에 남긴다. 부분연도(2026)·정부안(2027) 라벨. 개인정보 열은 정제본에서 제외.
→ 관세청: 세부코드 → 품목군(HS6)·국가·월/연 집계, 수출액 병행.
→ 국외 조달계획: 재고번호에서 군급 추출, FSG 58·59·60 선별, 적용장비명 표기 통일. 국산화개발품목은 완전 중복 제거 후 군급별 부품·사업 수 집계.
→ 예산·산업: 단위 통일(천원→억원), 사업명 개편 구간은 상위 사업 합계로 연결, 가로형 통계는 세로형으로.

**3. 분석(EDA)** — 분석 단위는 품목군·국가·군급·군·연도. 모든 지표를 2025(기준 연도) / 2021~2025(최근 5년) / 2016~2026.08(전체) 3단으로 본다.
→ 어느 나라에 얼마나: 상위 1개국 점유율·HHI·교역국 수, 50% 참고선 [13]
→ 구조가 바뀌었나: 1위 공급국 교체 시점, 19개 품목군 2021 vs 2025 HHI 대응 비교(윌콕슨 부호순위)
→ 큰 품목일수록 쏠렸나: 수입액 × HHI 순위상관(스피어만)
→ 어디에 쓰이나: 군급 × 적용장비 빈도, 육·해·공별 전자 군급 비중 차이(카이제곱, 소표본 표시)
→ 국산화는 어디까지: 군급별 국산화개발 부품 수와 국외 조달계획 건수를 나란히(비율 계산 없음)
→ 보조: 수출/수입 비율(민수 포함 명시), 통신전자 가동률·생산지수 추이(인과 해석 없음)

**4. 시각화** — 국가·계열 구분에만 색을 쓰고 의존도는 단일 색 농도. 위험·정상을 뜻하는 빨강·초록, 3D·게이지는 쓰지 않는다. 세계지도(국가별 수입액), 100% 누적막대(국가 구성, 50% 참고선), 선(월별 추이·예산), 히트맵(군급 × 적용장비), 산점도(수입액 × HHI).

**5. 대시보드 화면** — 홈 + 5탭. 각 탭은 상단 KPI·중앙 그래프·하단 표 구조.
| 탭 | 답하는 질문 | 핵심 요소 |
|---|---|---|
| 홈 | 한눈에 | KPI(품목군 19 · 2025 수입 499억 달러 · 특정국 50% 이상 품목군 수(잠정) · 전자 군급 조달계획 건수(잠정)) · 세계지도 · 「국가 전체 수입, 민수 포함」 고지 |
| ① 수입 의존도 | 어느 나라에 얼마나 | 품목군·기간 필터, 국가 구성 누적막대, 월별 추이(수출 선 토글), 국가별 표·HS10 상세 |
| ② 부품 → 무기체계 | 어디에 쓰이나, 국산화는 | 군급 × 적용장비 히트맵, 적용장비 목록, 국산화 패널(국산화개발 부품 수 ↔ 국외 조달계획 건수, 「국산화율 아님」 라벨) |
| ③ 품목군 현황표 | 19개를 한 표로 | 선정 근거 · 수입액 · 1위국 · 점유율 · HHI · 수출/수입 비율 · 관련 군급, 산점도, CSV |
| ④ 정책·산업 배경 | 정책과 국내 기반은 | 예산 추이(국방기술개발·부품국산화·국방반도체), 국외조달 집행유형, 가동률·생산지수 |
| ⑤ DATA INFO | 어디서 온 숫자인가 | 출처·기간·기준일, 선정 규칙, 단계별 건수, 쓰지 않은 데이터와 이유, 자료별 한계 |
화면별 상세 배치는 화면 설계서에.

데이터 요건(2종 × 1만 건 이상)은 1번(294,420행)과 3번(33,965행)으로 충족한다. 열 정의·건수·확보일·SHA-256은 데이터 명세서에.

**데이터 모델링** — AWS RDS MySQL 8.4. 원본(raw_) → 참조·규칙(ref_) → 정제(clean_) → 화면용 뷰(v_), 출처·건수는 meta_. 수입 축(HS: 품목군 → 세부코드 → 월별 수출입 ← 국가)과 군수품 축(FSG → FSC → 국산화개발품목·NSN·국외 조달계획)을 분리하고 직접 결합하지 않는다. 예산·산업 자료는 연도 기준 독립 테이블. ERD와 테이블 정의는 DB 설계서에.

**● 수행 도구**
Python 3 · pandas · scipy · matplotlib · seaborn · folium · Streamlit · AWS RDS MySQL 8.4(DBeaver) · Git/GitHub · Slack · Google Drive
