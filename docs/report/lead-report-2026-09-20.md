## 5. 팀 확정이 필요한 것 (09-21 회의)

1. **주제 확정** — 기획서 v7(수입 의존도 · 국산화 현황 + 부품→무기체계)로 갈지. 확정되면 `CLAUDE.md` 핵심 설계 제약 · `docs/idea-review.md` · `dashboard-scope` 갱신이 뒤따른다. 다른 곳은 `project-plan-v7-brief-2026-09-19.md` §9.
2. **1만 건 요건 데이터** — v7은 「관세청 수출입 + 국산화개발품목」. 국내조달 계약(43,112행)은 화면에 쓰지 않고 DATA INFO에만 둘지. 기획서의 국산화개발품목 33,965행과 DB 적재 건수의 관계는 아직 대조하지 않았다.
3. **작업 범위 자르기** — 필수: 홈 · ① · ③ · ⑤ / 범위 축소: ②(장비명은 상위 빈도 + 후보 40종) / 보류 후보: 조회 페이지 · NTIS · 권한별 화면 · 5분류 · 과천 추정.
4. **v7 표기 3건** — 19개를 「17 + 비교용 2」로 쓸지, NTIS 줄(키 미발급이면 삭제), 작성일자.
5. **시군구별 수입(273,586행)** — RDS에 적재할지. 과천 비중(군 직접 수입 하한 추정)은 추론이 섞여 Q&A 위험이 크다 — 쓰더라도 보조 설명으로.
6. **제출 저장소** — 제출은 팀 저장소(`tchoco313/defense_dashboard`) 기준으로 보고, EDA 노트북 · 앱 코드를 언제 · 누가 올릴지. 현재 팀 저장소에는 EDA 2종 · 앱 코드 · `scripts/contract_name_tokens.py`가 없다.
