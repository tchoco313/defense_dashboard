# CSV 파일 인벤토리·기대효과·누락 검토 (2026-09-14)

기준 문서: `docs/idea-review.md` §4·§5, `docs/data-sources.md`, `docs/report/plan/dashboard-scope-2026-09-14.md`. 저장소 `data/` 아래 CSV **47개**(참조 1 + 방사청 3 + 관세청 42 + 진행 로그 2)를 pandas 파서(`read_csv(dtype=str)`)로 직접 읽어 집계했다. 물리 줄 수는 참고로만 적고 레코드 수로 쓰지 않았다(모든 파일이 "물리 줄 = 레코드 + 헤더 1"로 셀 내 개행 없음). §1 핵심 건수는 부록 스크립트로 재실행해 재현을 확인했고, §2의 세부 분포는 같은 날 탐색 집계값이다.

## 1. 결론

- 확보된 CSV는 설계(`idea-review.md` §5 절충안)의 **핵심 1(관세청 A1)·1만 건 요건(계약정보)·조달 보조(입찰공고·입찰결과)** 를 모두 갖췄다. 수량·최신 연도 판정은 `dashboard-scope` §2와 동일(관세청 268,909행, 계약정보 2025 단독 30,808건).
- 공백은 두 가지다. ① **핵심 2 축(B1 KRIT)의 정형 CSV가 0건** — `data/raw/krit/` 디렉터리가 없고 `parse_krit.py`가 실행되지 않았다. ② 설계가 전제한 **참조표 CSV 3종**(품목군 대응표, 국가 좌표, 시도 정규화)이 아직 없다.
- 입찰공고 CSV는 현재 §4 페이지 표에 배정된 차트가 없다. 확보 상태는 유지하되 "보조" 이상으로 표현하지 않는다.
