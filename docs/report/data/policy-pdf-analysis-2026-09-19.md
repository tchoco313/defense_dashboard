## 3. 추진 배경 — 핵심 수치와 용어 정의

### 「국방반도체」 정의 (【참고1】)

민간·방산업체가 생산하는 반도체 소자 중 **국방 관련 전자장비·장치에 적용(예상)되는 반도체**. 중점 대상은 두 가지다.

1. 해외 도입 물자 중 전략물자에 포함될 수 있는 소자·기술(수출허가 E/L 위험)
2. 단종 예상 또는 성능 안정화를 위해 반드시 국산화해야 하는 소자

품목이 아니라 **용도로 정의**돼 있어서 HS 코드나 FSC로 일대일 식별이 되지 않는다. 팀이 관세청 데이터에 붙이는 「국가 전체 수입(민수 포함)」 라벨이 맞는 이유를 이 문서가 뒷받침한다.

### 핵심 수치 (본문 17-1)

> 레이더, 유도무기, 군통신 등 **54개 무기체계** 적용 국방반도체 조사 결과(**'23년. 12월**) **98.9%가 해외에서 도입**

### 논리 구조

- **공급망 확보**: 미중 기술패권, 양안 관계
- **국산화 필요**: 국정과제 「AI 기반 유·무인 복합전투체계」, Kill-Web·모자이크전을 시스템반도체가 이끈다는 주장(【참고2】)
- 문서 스스로 "국방반도체 발전전략은 제대로 수립된 적이 없음"이라고 적는다.
- 이 문서도 「수출 증가 → 부품 노출 증가」 같은 인과는 주장하지 않는다. 팀 스토리 라인 원칙(98.9%는 배경으로만)과 충돌하지 않는다.

## 5. 추진전략별 분석

### ① 설계 — 문서에서 가장 독창적인 부분

**1-1. 반도체 중심 획득절차 (【참고6·7】)**

- 현행: 요구 성능 → 부분품 설계 → 부분품마다 상용 반도체나 협력사·제조사 지정 반도체를 나중에 적용. 구성품이 많아져 초소형·저전력이 어렵다.
- 개선: 핵심기술 단계에서 기술별 IP를 조합·패키징해 단일 칩으로 만든 뒤 체계개발에 적용(기술 A·B·C → 「반도체ABC」 하나). 성능개량도 S/W와 반도체 개량으로.

**1-2. 범용칩 (【참고5·8】)**

- 위상배열(AESA) 레이더 · 데이터링크 · 해상 레이더의 공통 블록을 라이브러리로 만든다: GaN/GaAs PA·LNA·limiter / MMIC·Core IC / SoC(**AD9371** 명시) / 디지털 신호처리 IC / PMIC(DCDC·LDO).
- 이것을 이종집적 패키지(SHIP)로 묶는 「Any Chip」 구상. 절차는 기술분석 → 경제성 분석 → 최적화 개발.
- AD9371은 Analog Devices(미국)의 상용 RF 트랜시버다. 대체 대상이 미국산 상용 칩임을 문서가 직접 보여 준다. **생산지는 문서에 없으므로 언급하지 않는다.**

## 6. 비판적 평가 (💬 Claude 의견)

**강점**

#### 참고5 상세 — SHIP는 하나의 칩이 아니라 하나의 패키지

그림은 왼쪽에서 오른쪽으로 읽는다.

1. **유형별 라이브러리를 각자 최적 공정으로 개발**: RF SDR SoC Library(주파수·성능별) / 디지털 IP Library(표준·방식별 ⇒ 신속한 ASIC) / MMIC·Core IC Library(주파수·성능별) / 고출력 RF(GaN 소자 기반) / 전원·I/F IC / 기타 IC / 센서 IC
2. **각각을 별도의 다이(die)로 제작**: die 1 RF MMIC + die 2 RF SDR + die 3 디지털 ASIC + die 4 전원 IC + die 5, 6 …
3. **여러 다이를 한 패키지에 조립**: 「첨단 이종집적 패키지(SHIP)」. 그림 속 패키지 위에는 전원 IC, 센서 IC, 디지털 ASIC(AI·신호처리·통신), RF MMIC, RF SDR SoC가 나란히 올라가 있다.

- 칩 하나로 합치지 않는 이유는 공정이 다르기 때문이다. 고출력 PA는 GaN, 디지털은 Si CMOS라 한 웨이퍼에서 같이 만들 수 없다. 그림 제목이 「유형별 **최적 공정**으로」인 이유다.
- 다이를 따로 만들면 무기체계마다 다이 조합만 바꿔 끼울 수 있다. 이것이 「범용 플랫폼」이고 「Any Chip」은 그 플랫폼의 이름이다(참고14에도 같은 이름으로 등장). 소량 다품종이라는 국방 수요의 약점을 다이 단위 재사용으로 메우려는 구상이다.
- 본문 근거: 1-1 "각 기술별 요구조건을 충족할 수 있는 반도체 설계자산(IP)을 조합, **패키징을 통해** 단일 반도체화", 1-2 ❸ "반도체를 기능별 개발 및 라이브러리화하고 프로그래밍이 가능한 범위를 극대화".
- SHIP는 미 국방부의 이종집적 프로그램(State-of-the-Art Heterogeneous Integration Prototype) 이름과 같다. 문서에 출처 표기는 없으므로 「가져온 것으로 보인다」까지만 말한다.

**네 도표의 연결**: 참고8(체계가 달라도 공통인 칩이 무엇인가) → 참고9(그 칩을 7대 유형으로 분류) → 참고5(유형별 다이를 한 패키지로 조립) → 참고14(디지털 쪽은 IP → ASIC → Any Chip).
