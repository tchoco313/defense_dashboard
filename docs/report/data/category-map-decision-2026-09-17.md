## 1. 결정 원칙 (기존 문서 그대로) — *(2026-09-18 폐기된 원안 기록)*

1. 대응은 **품목군 수준**(FSC4 → HS6)이다. 부품 하나가 HS6 하나에 정확히 속한다는 뜻이 아니다(`docs/idea-review.md` §5, CLAUDE.md).
2. 한 FSC가 여러 HS6에 대응하면 같은 부품이 HS6마다 반복 집계된다. **HS6 간 합산 금지** 라벨을 붙인다(`schema.sql` `v_review_list` 주석, `hs-whitelist-definition.md` §7-3).
3. `link_status` 값은 ENUM `확정 / 후보 / 대응불가` 셋뿐이다. "제외"는 `대응불가`로 적고 사유를 `link_basis`에 남긴다.
4. 확정된 대응이 없는 HS6는 뷰가 `대응 미확정`(NULL)으로 표시한다. "확인된 없음(0)"으로 바꾸려면 뷰 라벨 규칙을 손봐야 한다(§4 후속).
5. B2는 지상 기동·화력체계 28개 사업의 완료 부품 목록이며 시점이 없다. "국산화율"·"국산화됨"으로 쓰지 않는다(§3-14).
