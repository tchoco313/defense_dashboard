# CSV 파일별 기능 → 구현 가능 목록 (2026-09-14, B2 채택 반영)

기준 문서: `docs/idea-review.md` §4 페이지 구성·§5 절충안(2026-09-14 B2 채택판), `docs/report/data/csv-inventory-2026-09-14.md`(파일별 품질 상세). 저장소 `data/` 아래 CSV **54개**를 pandas 파서(`read_csv(dtype=str)`)로 다시 읽어 레코드 수를 집계했다(2026-09-14 저녁, 재현 코드는 부록). 물리 줄 수가 아니라 파서 레코드 수이며, 헤더 행은 제외했다. 모든 원본 파일은 사용자 로컬 `data/raw/`에 실물로 존재한다(gitignore).

"구현 가능"은 **지금 있는 열만으로 만들 수 있는 화면 요소**를 뜻한다. 상태 표기: **바로** = 원본 열로 즉시 / **정제 후** = 사용자 노트북 정제(중복·분류·정규화)가 선행 / **참조표** = 수작업 참조 CSV(~~`category_map.csv`~~ 2026-09-18 작성하지 않기로 결정 → 해당 항목은 구현하지 않음, `sido_map.csv`)가 먼저 필요 / **조건부** = 연결률·표본 검수 결과를 본 뒤 결정.
