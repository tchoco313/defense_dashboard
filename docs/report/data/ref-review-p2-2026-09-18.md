## 1. `ref_hs_rule_flag` — 수정 없음, 기획서 문구 보완 필요

- **확인됨**: 1,003행, `rule_version` = 2026-09-16 한 개. `is_candidate_provisional` = `r1_mil OR r2_aero_nav OR (r3_du AND r4_b2)` 가 **1,003행 전부 일치**(불일치 0).
- **확인됨**: 화이트리스트 24개 중 규칙 충족 **19개**(v3 기획서와 일치). 근거 미확인 5개 = 847180 · 848620 · 851762 · 854142 · 854159.
- **`b2_part_count` 는 삭제하지 않는다**
  - `r4_b2 = 1` ⇔ `b2_part_count > 0` (1,003행 전부 일치) → R4의 근거값
  - 뷰 4개가 참조: `v_hs_whitelist_rule` · `v_hs6_candidate_rule` · `v_defense_relevance_b2` · `v_b2_fsg_summary`
  - **주의**: FSC 경유 값이라 같은 FSC를 공유하는 HS6끼리 같은 값(IC 3종 = 27, 반도체 소자 4종 = 15). **HS6 간 합산 금지**, 화면 라벨 「관련 군급 기준 · 후보」
- ⚠️ **규칙 충족 HS6는 전체 58개**, 화이트리스트 밖 **39개**. 대부분 84류 엔진·펌프·필터·베어링, 8511 점화장치, 9032 자동조절기기 — HSK 하위에 「항공기용」 세분류가 있어 R2에 걸린 것
  - 기획서는 "1,003개에 규칙 적용 → 수집 24개 중 19개"라서 **"58개 중 왜 19개?"**에 답이 없다 → **선정 2단계「전자·통신·광학 계열 한정(기계·엔진류 제외)」을 v4에 명시**(제안)
  - 841191(터보제트 **부분품**)은 비교용 포함인데 841111·841112(터보제트 **본체**)는 제외 → 한 줄 근거 필요
  - `hs6_name_ko` NULL 3개: 840710 · 842920 · 854430 (HS 개정 코드로 추정, 미확인)

## 2. `ref_category_map` — 17행 맞음, 수정 없음

- **확인됨**: 17행 = 화이트리스트 `related_fsc` 후보 쌍 수. FSC가 붙은 HS6 **14개** + FSC 2개인 HS6 3개(852990 · 852560 · 901380) = 17. R4 충족 HS6 수(14)와 일치.
- 전부 `map_type = fsc4`, `link_status = 후보`, `decided_by = load_db.py seed`. 확정하지 않는다(CLAUDE.md 설계 제약).
- (선택) `link_basis` 17행이 모두 같은 문구 → 행별 한 줄 근거(예: 「FSC 5962 Microcircuits ↔ HS 8542 집적회로」)로 채우면 좋음.

## 3. `ref_sido_map` — 토큰 2개 삭제, 1개 추가

- **방식**: 주소 `TRIM` → 첫 공백 앞 토큰 → `token` 정확 일치. 45행 = 17개 시도 × 정식명·약칭·「○○시」 변형.
- **확인됨 — 적용률**: 계약 `vendor_address` 43,112 중 **43,092 (99.95%)**, 낙찰 `winner_address` 주소 있는 5,276 중 5,275 (빈 주소 2,129 = 유찰 등).
- **확인됨 — 미매칭 21건**

| 토큰 | 건수 | 처리 |
|---|---|---|
| `충남대전시` | 16 | **토큰 추가 → 30** (1989년 대전 분리 전 표기) |
| `용산구 … 테스트` | 2 | 테스트 데이터 — 계약 전체에 「테스트」 포함 8행, P4 정제에서 제외 |
| `**`, `1 1` | 2 | 판별 불가, 미매칭 사유 기록 |
| 사람 이름 1건 | 1 | 주소 칸에 개인 이름 — 화면 비노출 |

- **광주 토큰 삭제 이유**: `광주`·`광주시`는 경기 광주시(41)와 겹친다. 현재 `광주시` 시작 0건, `광주` 시작 1건(`광주 서구` → 29)이라 **지금 결과는 안 바뀌고 이후 오류를 막는 조치**. 정제 규칙:
  - 첫 토큰 `광주`·`광주시` + 둘째 토큰 동구·서구·남구·북구·광산구 → 29
  - 그 밖의 읍·면·동 → 41 / 판별 불가 → 미매칭 `AMBIGUOUS_GWANGJU`
- 그 밖의 함정: 붙여 쓴 주소(「경기도성남시」)는 첫 토큰으로 못 잡음. 강원·전북은 새 코드 51·52 — 옛 코드 42·45 자료와 붙일 때 주의.
- **정정**: 관세청 시군구 API는 시도·시군구 코드를 직접 주므로 과천 지표(군 직접 수입)에는 `ref_sido_map` 이 필요 없다. 이 표는 **주소 문자열 전용**.

## 5. `raw_openfiscal_program_budget` — clean 신설 규칙

- **확인됨**: 2,860행(2016~2027), 업무키(연도·프로그램·단위사업·세부사업·경비·지출구분) 중복 **0**. 금액 열은 전부 쉼표 문자열(숫자 외 문자 0).
- 규칙
  1. `gov_plan_krw_k`·`confirmed_krw_k` 쉼표 제거 → 숫자, 억원 열 추가(÷ 100,000)
  2. **2027 `confirmed_krw_k` = 0 (268행 전부) → NULL + `is_unconfirmed = 1`** (미확정, 0원 아님)
  3. **2017~2026의 확정액 0원 10건은 0 유지** — 국회 전액 삭감(예: 2022 대형공격헬기 2차 154.11억, KDX-Ⅱ 성능개량). 2027 미확정과 섞지 않는다
  4. `sub_account_name` 전부 공란 → 제외
- 사업 개편(⑤ 탭 추이선 연결)

| 선 | 2016~2022 | 2023~ | 비고 |
|---|---|---|---|
| 국방 핵심기술 | 핵심기술개발(R&D) | 개별핵심기술(R&D) + 패키지 핵심기술(R&D) | 합계로 연결 |
| 부품국산화 | (2016~2020) 핵심부품·SW개발/신개념기술시범 | 부품국산화 개발지원(R&D), 2021~ | **2020 이전은 부품국산화만의 사업이 아님 → 선을 끊거나 「전신 사업」 라벨** |
| 국방반도체 | — | 국방반도체(R&D), 2027 정부안 56,507,000천원 = **565.07억** | v3 기획서 565.1억과 일치 |
