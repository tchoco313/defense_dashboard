## 3. 국방 데이터 취급 유의사항 (기획서 "고려사항"란에 반영)

1. 법적 경계 — 군사기밀보호법·방위사업법·방산기술보호법. 공개 데이터포털·정부 공고만 사용. 부대 위치·전력 수량·BOM은 수집·추정·역산하지 않는다.
2. 수집 방식 — OpenAPI 우선. 크롤링은 robots.txt·이용약관 확인, 저빈도, 원문 URL 보존.
3. 용도 혼합 — 모든 무역 차트에 "국가 전체 수입 기준(민수 포함)" 명시. "국방용 반도체 수입 ○○억" 표현 금지.
4. 원산지≠선적국 — 관세청은 CIF 선적국 기준. 홍콩·싱가포르 경유 물량 각주.
5. HS 개정 단절 — HS2022(2022-01)에서 8803→8807 등 변경. 시계열은 HS6 기준 + 개정 시점 표시.
6. 시나리오 라벨링 — 시뮬레이션 결과는 `is_scenario=true` 컬럼 + UI 배너.
7. 국가명 표기 — 관세청 코드표 명칭 그대로 사용.
8. 보안 — API 키는 `.env`만, 커밋 금지. 대시보드 로그인·role 최소 구현.
9. 표현 수위 — 특정 기업의 수입 의존 지목 금지, 품목군 수준으로 서술. 발표 자료에 기관 로고가 들어가므로 보수적으로.
10. 품목명세서 활용 — 입찰공고는 공개 자료이나, 적용장비명·부품번호를 조합해 특정 무기체계의 취약 부품을 특정하는 서술은 하지 않는다. 군급(FSC)·품목군 단위로 집계해 표현한다.
11. 수출 차트 용도 혼합 — HS 8526(레이더)·8525(송수신기)·8517 수출에는 자동차 레이더 센서·선박 레이더·민수 통신장비가 포함된다. "국가 전체 수출(민수 포함)" 라벨을 달고, 방산 한정 수치는 A4 분야별 수출액으로만 서술한다.
12. 조달 금액 ≠ 방산 매출 — 계약정보 CSV의 계약금액 합계를 방산 산업 매출액으로 표현하지 않는다. 차수별 변경·누계 의미를 확인한 뒤 집계하고, A4 매출액과 같은 화면에 놓을 때 출처·정의 라벨을 분리한다.
13. 계약업체 주소 ≠ 생산시설 — 입찰결과·계약정보의 업체 주소는 계약업체 소재지이며 생산시설이나 납품 위치가 아니다. 국내 지도 라벨에 "계약업체 소재지"로 명시하고, 부대 단위 집계·표시는 하지 않는다.
14. 국산화 완료 목록 ≠ 국산화율 (2026-09-14 추가) — B2 국산화개발품목은 지상 기동·화력체계 28개 사업의 완료 부품 목록이며 모수(전체 부품 수)가 없다. "국산화율 N%"·"○○ 품목군은 국산화됨"으로 쓰지 않고 "완료 부품 N건(지상체계 기준, 시점 미상)"으로 쓴다. 빈칸은 "국산화 안 됨"이 아니라 "이 자료에 없음"이며, 계약업체명은 국산화 개발 주체가 아니라 계약 상대라는 점을 라벨에 적는다.
15. 조달계획 예산 ≠ 수입액 (2026-09-15 추가) — A7 국외조달 조달계획 `예산금액`은 원화 **집행 예정액**(계획)이고 관세청 수입액은 CIF 달러 **실적**이며 범위(방사청 국외조달 vs 국가 전체 수입)도 다르다. 합산·비율·직접 비교를 하지 않고, 같은 화면에 두면 출처·단위·기준(계획/실적)을 라벨로 분리한다. 진행상태가 `계약`이 아닌 행은 집행 확정이 아니므로 "집행 예산"이라 쓰지 않는다. 국외 계약정보의 업체명으로 국가를 추정하지 않는다. 전자 관련 후보는 `대표품명` 키워드 분류이므로 검수 범위·오탐 예를 함께 보고하고, 검수 전 값은 "잠정"으로만 쓴다.

- What: 핵심 질문 하나 — "어떤 전자부품군의 수입이 특정 국가에 집중되어 있으며, 국외조달 예산 추이와 조달·국산화 자료를 볼 때 국산화 정책 검토가 필요한 품목군은 무엇인가?"

  - 하지 않는 것: 무역전쟁 피해액 예측, 취약 무기체계 특정, 방산 한정 수입액 산출, 국가별 예산 산출(조달 CSV에 국가 없음), 예산과 수입액 합산, 우선순위 "확정"

- 핵심 지표: (배경) 국외조달 연도별 예산·집행유형 구성·전자 관련 후보 비중(검수 후, 계획 기준 라벨)·군별 계약집행 총액 / 품목군별 수입액·상위국 점유율·HHI·국산화 상태(각각 표시, 가중 합산 없음) / 국내 조달 월별 계약·물품/용역·5분류 구성(계약정보 CSV) / 국산화 대상 과제 수(B1) / 국산화 완료 부품 수 — FSC별·사업별(B2, 지상체계·시점 미상 라벨) / (보조) 전자부품군 수출액 추세·수출국 구성(관세청), 방산 통신전자 분야 수출액·가동률(A4)·생산지수(A5)
- 갱신: 무역통계 월 1회, 생산지수 월 1회, 방산 경영분석 연 1회, 국산화 공고 분기, 조달계획·계약정보 파일데이터 연 1회
