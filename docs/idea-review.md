## 3. 국방 데이터 취급 유의사항 (기획서 "고려사항"란에 반영)

1. 법적 경계 — 군사기밀보호법·방위사업법·방산기술보호법. 공개 데이터포털·정부 공고만 사용. 부대 위치·전력 수량·BOM은 수집·추정·역산하지 않는다.
2. 수집 방식 — OpenAPI 우선. 크롤링은 robots.txt·이용약관 확인, 저빈도, 원문 URL 보존.
3. 용도 혼합 — 모든 무역 차트에 "국가 전체 수입 기준(민수 포함)" 명시. "국방용 반도체 수입 ○○억" 표현 금지.
4. 원산지≠선적국 — 관세청은 CIF 선적국 기준. 홍콩·싱가포르 경유 물량 각주.
5. HS 개정 단절 — HS2022(2022-01)에서 8803→8807 등 변경. 시계열은 HS6 기준 + 개정 시점 표시.
6. 시나리오 라벨링 — 시뮬레이션 결과는 `is_scenario=true` 컬럼 + UI 배너.
7. 국가명 표기 — 관세청 코드표 명칭 그대로 사용.
8. 보안 — API 키는 `.env`만, 커밋 금지. 대시보드 로그인·role 최소 구현.
9. 표현 수위 — 특정 기업의 수입 의존 지목 금지, 품목군 수준으로 서술. 발표 자료에 기관 로고가 들어가므로 보수적으로.
10. 품목명세서 활용 — 입찰공고는 공개 자료이나, 적용장비명·부품번호를 조합해 특정 무기체계의 취약 부품을 특정하는 서술은 하지 않는다. 군급(FSC)·품목군 단위로 집계해 표현한다.
11. 수출 차트 용도 혼합 — HS 8526(레이더)·8525(송수신기)·8517 수출에는 자동차 레이더 센서·선박 레이더·민수 통신장비가 포함된다. "국가 전체 수출(민수 포함)" 라벨을 달고, 방산 한정 수치는 A4 분야별 수출액으로만 서술한다.
12. 조달 금액 ≠ 방산 매출 — 계약정보 CSV의 계약금액 합계를 방산 산업 매출액으로 표현하지 않는다. 차수별 변경·누계 의미를 확인한 뒤 집계하고, A4 매출액과 같은 화면에 놓을 때 출처·정의 라벨을 분리한다.
13. 계약업체 주소 ≠ 생산시설 — 입찰결과·계약정보의 업체 주소는 계약업체 소재지이며 생산시설이나 납품 위치가 아니다. 국내 지도 라벨에 "계약업체 소재지"로 명시하고, 부대 단위 집계·표시는 하지 않는다.
